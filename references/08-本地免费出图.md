# 08 · 本地免费出图出视频（ComfyUI：Z-Image / Anima / Qwen-Image / MiniMax H3）

> **一句话定位**：云端出**定稿**，本地出**草稿**。
> 本地不是用来替代 Seedream 的，是用来把「试错」这一步的成本降到 0。

---

## 一、什么时候走本地，什么时候必须上云端

| 场景 | 走哪边 | 原因 |
|---|---|---|
| 试构图、试发型、试服装配色 | **本地** | 一次几十秒，不花 token，随便抽 |
| 批量出表情状态图（20 张起） | **本地** | 云端按张计费，量大肉疼 |
| 角色三视图**第一次定稿** | **云端** | 白底干净度、多视角一致性，云端明显更稳 |
| 带文字的图（封面、标题卡） | **云端** | 本地模型中文渲染不稳 |
| 需要 >10 张参考图的复杂合成 | **云端** | 本地显存吃不下 |
| 需要分层 PNG / 定点框选改图 | **云端**（Seedream 5.0 Pro） | 本地没这能力 |

**工作流接法**：本地抽 20 张草稿 → 挑 1 张构图最对的 → 把那张当**参考图**丢给云端 Seedream 5.0 Pro 出定稿。
这样一张定稿只花一次云端的钱，而不是抽 20 次。

## 二、Z-Image Turbo 本地部署（8GB 显存可用）

Z-Image 是阿里开源模型，Turbo 是蒸馏版 —— **8 步出图**，消费级显卡能跑。

### 2.1 节点结构（照抄）

```
UNETLoader(z_image_turbo_int8_convrot)  ─┐
CLIPLoader(qwen_3_4b_fp8_mixed, lumina2) ┴→ ModelSamplingAuraFlow(shift=3) → KSampler
VAELoader(ae.safetensors)                                                  ↓
EmptySD3LatentImage(832×1216) ─────────────────────────────────────→ VAEDecode → SaveImage
CLIPTextEncode(正向) ─→ 正向
CLIPTextEncode/Nothing ─→ ConditioningZeroOut ─→ 负向（等于空负向）
```

### 2.2 参数表（**这套是官方调的，别乱改**）

| 项 | 值 | 说明 |
|---|---|---|
| 分辨率 | **832×1216**（竖屏漫剧） | 别往上加，8GB 会爆 |
| 步数 | **8** | Turbo 蒸馏，多给步数不加质量 |
| CFG | **1.0** | ⚠️ **必须 1.0**。Turbo 是蒸馏模型，cfg > 1 直接糊 |
| 采样器 | `res_multistep` + `simple`（官方） | 或者 `euler` + `sgm_uniform`，二选一 |
| shift | `ModelSamplingAuraFlow` = **3** | 官方模板默认 |
| 负向 | `ConditioningZeroOut`（空） | Turbo 的负向基本无效，别浪费字数 |
| CLIP type | **`lumina2`** | ⚠️ 不能选错，选错直接报错或出噪声 |
| 系统内存 | 32GB 舒服 | 模型在 8GB 显存外分页 |

### 2.3 模型文件清单

| 文件 | 放到 | 大小 |
|---|---|---|
| `z_image_turbo_int8_convrot.safetensors` | `models\diffusion_models\` | 5.78 GiB |
| `qwen_3_4b_fp8_mixed.safetensors` | `models\text_encoders\` | 5.25 GiB |
| `ae.safetensors` | `models\vae\` | 0.31 GiB |
| `4x-UltraSharp.safetensors` | `models\upscale_models\` | ~67 MB |
| `RealESRGAN_x4plus.safetensors` | `models\upscale_models\` | 63.8 MB |
| `Z-Image-Turbo-Fun-Controlnet-Union-*-lite-*.safetensors` | `models\model_patches\` | 1.88 GiB |

**合计约 11.3 GiB。** 装之前先确认磁盘余量。

下载源：ModelScope 官方同步仓 `Comfy-Org/z_image_turbo`（国内直连快）→ 备用 `hf-mirror.com`。

> ⚠️ **`ae.safetensors` 不是 Qwen 的 VAE，也不是 Wan 的。**
> Z-Image 用 **Flux 系 16 通道 VAE**，拿 Qwen-Image 的 VAE 顶替会**偏色**。
> 这是本地出图最常见的"为什么我的颜色怪怪的"根因。

### 2.4 官方工作流模板（ComfyUI 自带，零下载）

ComfyUI **Workflow 菜单 → Browse Templates → 搜 `z-image`**，一共 6 个：

| 模板 | 干什么 | 8GB 能不能跑 |
|---|---|---|
| `image_z_image_turbo_int8.json` | **Turbo 文生图 INT8 ← 主力** | ✅ |
| `image_z_image_turbo.json` | Turbo 文生图 bf16 | ❌ 权重 11.46GB，装不下 |
| `image_z_image_turbo_fun_union_controlnet.json` | ControlNet 控制出图（姿势/深度/边缘） | ✅ 需手选 lite 版 |
| `utility_z_image_turbo_2k_upscaler.app.json` | 图 → 2K 放大 | ✅ |
| `image_z_image_int8.json` | Base 非蒸馏版（30–50 步、有真负向） | ✅ 慢，**训 LoRA 才用它** |
| `image_z_image.json` | Base bf16 | ❌ |

> ⚠️ **ControlNet 模板的文件名对不上**：官方 JSON 里写死 `Z-Image-Turbo-Fun-Controlnet-Union.safetensors`（2.89GB 完整版）。
> 用 lite 版一样能跑，只要在 `ModelPatchLoader` 节点的**下拉框里手动选中** lite 文件名即可。
> ⚠️ **2K 放大模板只认 `RealESRGAN_x4plus`**，换别的放大模型要先改节点。

## 三、放大 + 细节修复链（"出完图糊"的解药）

Z-Image 8 步出图分辨率不高，**必须接放大链**才能当资产用。

```
Z-Image 8 步出图
  → UpscaleModelLoader + ImageUpscaleWithModel（4x-UltraSharp）
  → ImageScaleBy
  → 第二个 KSampler（低 denoise 补细节）
  → SaveImage
```

### 3.1 ImageScaleBy 实测倍率

| ImageScaleBy | 净倍率 | 1280×720 出来的尺寸 |
|---|---|---|
| 0.25 | ~1× | 原尺寸 |
| 0.5 | ~2× | ~2560×1440 |
| 0.75 | ~3× | ~3840×2160 |
| 1.0 | 4× | ~5120×2880 |

### 3.2 细节 pass 的 denoise（关键）

- **0.2 – 0.4，默认 0.3**
- 低于 0.2：看不出变化，白跑
- **高于 0.4：开始改构图、换脸** ← 这是"放大完脸变了"的根因

### 3.3 细节提示词两套起手式

- **人像**：`skin texture, skin pores, detailed skin, natural sunlight on face and skin`
- **动物/毛发**：`fur detail, individual strands, sharp eyes, natural skin texture, realistic coat`

## 四、8GB 显存翻车点（记住这几条就不会炸）

| 症状 | 原因 | 修法 |
|---|---|---|
| CUDA out of memory | 放大倍率太高 | ImageScaleBy 降到 **0.25**（细节 pass 回原分辨率跑） |
| 还是爆 | 出图分辨率太高 | 降到 **912×512** |
| 画面**过锐/发脆**、像被锐化过 | denoise 太高 / 放大模型太狠 | denoise 降回 **0.2**；把 4xFaceUpDAT 换回 4x-UltraSharp |
| **脸变了** | denoise > 0.4 | 降回 0.3 以下 |
| 颜色偏了 | VAE 用错 | 确认是 **Flux 系 16 通道** `ae.safetensors` |
| **整张糊** | cfg > 1 | 改回 **1.0** |
| 出噪声/报错 | clip type 选错 | 必须是 **`lumina2`** |
| 多给步数没变好 | Turbo 是 8 步蒸馏 | 别加步数，加步数只变慢 |

## 五、本地出图在漫剧流程里的三个接法

### 5.1 角色三视图 —— 本地抽构图，云端定稿

本地抽 10–20 张，挑「脸型+身形比例」最对的一张 → 上传云端当参考图 → 出干净白底定稿。
本地那张不用白底、不用干净，**只要比例对**。

### 5.2 表情状态图 —— 本地批量出

落泪 / 咬牙 / 冷笑 / 惊恐 这类状态图，一集可能要 5–10 张。
用 ControlNet（姿势/深度）锁住头部角度，**同一 seed 换表情提示词**批量出，成本为 0。

### 5.3 场景空镜 —— 本地出草稿，云端出终版

空镜对细节要求低、对**空间布局**要求高。本地快速试 5 种布局 → 选中的布局描述写进云端 prompt。

### 5.4 用 ControlNet 锁姿势（解决"三视图对不上"）

`image_z_image_turbo_fun_union_controlnet.json` 支持姿势/深度/边缘三种控制：
- **姿势**：给一张火柴人骨架图，锁住人物朝向和四肢
- **深度**：给一张灰阶深度图，锁住前后景关系（做场景空镜很好用）
- **边缘**：给线稿，锁住轮廓

> 三视图最容易翻车的地方是**三个视角的身高和头身比不一致**。
> 用姿势控制 + 固定 seed，比纯提示词可靠得多。

## 六、和云端的分工（结论）

```
本地 Z-Image Turbo          云端 Seedream 5.0 Pro / Nano Banana Pro
─────────────────────       ─────────────────────────────────────
抽构图、抽配色、抽姿势        出定稿三视图（白底干净）
批量表情状态图                带文字/排版/封面
场景空镜布局试错              需要 >10 张参考图的复杂合成
                             分层 PNG / 定点框选编辑
     ↓ 挑 1 张当参考图 ↓
              ────────────────→
```

**成本模型**：本地从 20 张里挑 1 张，云端只为这 1 张付费。
比起直接在云端抽 20 次，省下来的就是纯利润。

## 八、Anima（二次元出图）

- 2B 参数的动漫 / 插画模型，ComfyUI 原生支持：模板库搜「Anima」直接用官方工作流
- 三个文件：扩散模型放 `models/diffusion_models/`，文本编码器放 `models/text_encoders/`，VAE 放 `models/vae/`（文件名以 Hugging Face 上 `circlestone-labs/Anima` 当前版本为准）
- 提示词：Danbooru 标签和自然语言可以混写；**提示词太短容易跑偏**，把发型、服装、构图都写全
- 参数（社区文档的推荐值，以官方模板为准）：Base 30–50 步、CFG 4–5；Turbo 8–12 步、CFG 1；分辨率 512²–1536²
- 不擅长：写实、图里写字
- **许可**：非商业。同人期放心用；原创商业项目的成品别用它出

## 九、Qwen-Image 2.1 Turbo（编辑 + 分层素材）

- Qwen-Image 2.1 一个模型同时管文生图和指令编辑，原生 2K，支持**透明背景**
- Turbo 版是社区蒸馏 LoRA：约 6 步出图、不用 CFG；小字比完整版弱，要排字就加步数或换完整版
- 在本流程里的三个用法：
  1. **改图**：带 1–3 张参考图，「把她的外套换成白色风衣」「改成侧脸」
  2. **分层素材**：Q 版角色、纸张、胶带、贴纸、图标直接出透明 PNG，丢进 AE（见 `13-拼贴风MV.md`）
  3. **封面中文字**
- **许可**：基础模型和 Turbo LoRA 分开核对

## 十、MiniMax H3（本地视频试错）

- 开放权重的视频模型，ComfyUI 原生支持（官方工作流模板）
- 本地版：4–15 秒、24fps、带声音、支持首帧 / 首尾帧；**本地最高约 768p**（2K 需要官方云端的增强组件）
- 约 33B 参数：官方推荐高端显卡；社区有低显存方案，越低越慢、质量越差。**8GB 显卡只当预演用**
- 用法：同一个关键帧先在 H3 上试运镜和动作 → 满意的方案原样拿去 Seedance 2.5 定稿；无台词镜头 H3 够好就超分后直接用
- 24fps 素材放进 25fps 工程：AE 里「解释素材」设为 25（速度快 4%，无台词镜头看不出来）
- **许可**：商用有条件，部分国家和地区禁止本地部署，用前读模型卡
- **跑 AI 和 AE 渲染都吃显卡，不要同时开**
