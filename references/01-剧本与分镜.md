# ① 立项 · ② 剧本与分镜

---

## 一、题材配方（直接照抄骨架）

| 题材 | 主角模板 | 反派模板 | 开场 6 秒 | 每集爽点类型 | 受众 |
|---|---|---|---|---|---|
| **女频复仇 / 逆袭** | 圆脸、被夺走一切、隐忍后反杀 | 尖下颌、笑面、掌控欲 | 主角被公开羞辱 / 失去至亲 | 打脸、身份揭穿、反手夺权 | 25–45 女性 |
| **玄幻升级** | 方脸、被废柴标签压住、觉醒 | 倨傲师兄 / 家族长老 | 当众被逐出师门 | 碾压、逆袭、亮底牌 | 18–35 男性 |
| **都市异能** | 普通人突然获得能力 | 组织高层 / 同类竞争者 | 能力首次失控 | 装逼、反转、势力登场 | 18–35 通吃 |
| **沙雕日常** | 憨圆脸、运气逆天 | 无真正反派 | 荒诞误会 | 笑点、反差、群像嘴炮 | 全年龄 |
| **豪门狗血** | 真假千金 / 隐婚 | 假千金 / 恶婆婆 | 婚礼上被换掉 | 身份反转、揭穿、争产 | 30–55 女性 |

**先给用户 5–6 个方向的候选**（同题材下的不同切入角度），他选定一个再展开。禁止直接写完整剧本。

---

## 二、3+3+3 法则（短剧节奏骨架）

> **30 秒内：3 个钩子留住手指 · 3 次起伏推着情绪走 · 3 个冲突制造期待**

- **钩子**：让人不划走的信息点（一个动作、一句话、一个物件）
- **起伏**：情绪的上下 —— 平静 → 被激怒 → 反压
- **冲突**：两个意志的对撞，不是"发生了什么事"

一集 60 秒 = 两轮 3+3+3，或一轮加强版。

## 三、黄金前 6 秒（必须写死）

| 时间 | 必须发生什么 |
|---|---|
| 0–1s | **画面就要有信息**：一个异常状态 / 一个动作 / 一张脸。不要空镜开场 |
| 1–3s | 建立"谁、在哪里、出了什么事" |
| 3–6s | 第一个冲突或疑问抛出（**这是完播率的生死线**） |
| 6–15s | 第一次情绪起伏 |
| 结尾最后 3s | 留钩（见下表） |

**三种万无一失的开场**：
1. **结果前置**：先给最惨/最爽的画面，再倒回去讲
2. **台词入画**：一句带冲突的话直接砸下来（"你以为你配？"）
3. **物件特写**：一个带信息量的道具（染血的请柬、碎掉的婚戒）

## 四、台词密度规范（直接决定口型同步质量）

| 项 | 数值 |
|---|---|
| 中文语速（短剧偏快） | **5 字 / 秒** |
| 单句长度 | **6–14 字**（≈1.5–3 秒） |
| 单段（6–10 秒）台词总量 | **≤ 2 句 / ≤ 25 字** |
| 单句时间戳缓冲 | **实际发音时长 + 0.5 秒** |
| 一条生成内语言 | **只能一种**（中英混写会出错） |

**超过 14 字的句子必须拆**。拆不动的，把动作和停顿写进去：

```
❌ 0s-3s：她说{我早就知道你和我姐姐联手骗了我这么多年我只是没说而已}
✅ 0s-2s：她垂眼看酒杯，说{你和姐姐的事，我早就知道}。
   2s-2.5s：停顿。她抬眼。 <玻璃轻碰声>
   2.5s-4s：她说{我只是，没说而已}。语气很轻，嘴角没有笑意。
```

## 五、结尾钩子类型（每集换一种，别重复）

1. **身份揭穿前 0.5 秒切断** —— 最有效
2. **关键人物只给背影 / 侧脸入画**
3. **一句反转台词**（"你以为这是结束？"）
4. **物件特写**：掉落的照片、震动的手机、信封的一角
5. **手机屏幕内容**（短信 / 通话记录）—— 注意这会引入画面文字，需谨慎
6. **反派冷笑特写，定格**
7. **时间跳字**："三年后"—— 用转场实现，别让模型在画面里写字
8. **主角眼神变化定格**：从忍到不认，一个眼神

## 六、集数规划

| 阶段 | 集数 | 目的 |
|---|---|---|
| **试播** | 1 集 | 验证画风、脸、音色、节奏是否成立 |
| **备播** | 3 集 | 排播不断档，验证追更意愿 |
| **正式** | 4–20 集 | 跑量 |
| **长线** | 20+ 集 | 需要系列圣经 + 资产库长期维护 |

**剧集大纲表**（写进 `01_剧本/剧集大纲.md`）：

| 集号 | 一句话剧情 | 本集爽点 | 结尾钩子类型 | 新增资产 |
|---|---|---|---|---|
| 01 | … | … | 身份揭穿前切断 | 林晚、苏黎、婚礼厅 |
| 02 | … | … | 关键人物入画 | 陆沉、车库 |

## 七、分镜表（固定列，别再自己发明）

**每行 = 一个时间片**，同一段号的多行合并成一条生成，**每段 4–12 秒，推荐 6–10 秒**。完整列定义（含段概述、合并到）以 `assets/分镜表模板.md` 为准。

| 列名 | 说明 |
|---|---|
| 段号 | seg01、seg02……与成片文件名一致 |
| 时间区间 | 段内相对时间，如 `0s-3s`；**同段内区间不得重叠** |
| 段时长 | 段总时长（秒），4–12，推荐 6–10 |
| 场景 | 内景/外景 + 具体地点 |
| 景别 | 远景/全景/中景/近景/特写 |
| 运镜 | 推/拉/摇/移/跟/升降/固定 + 视角词 |
| 画面内容 | 写"看到什么"，不写情绪形容词 |
| 动作细节 | 肢体细化 + 程度量化，见 `03-提示词工程.md` |
| 台词 | 原文，**不带 `{}`**（脚本自动加） |
| 说话人 | 角色名，**不许写"角色1"** |
| 音效 | **不带 `<>`**（脚本自动加） |
| 参考素材 | 写编号表编号，如 `@图片1;@图片6`；有台词的角色必须挂自己的 `@音频N` |
| 段守则 | 本段的红线（一般直接抄系列圣经的禁项） |

### 时长分配公式

| 一集时长 | 建议段数 | 每段时长 |
|---|---|---|
| 60 秒 | 6 段（B 派）或 2 段（A 派） | 6–10 秒 |
| 90 秒 | 8–9 段 | 6–10 秒 |
| 120 秒 | 10–12 段 | 6–10 秒 |

**超过 12 秒的段明显变质**（10–12 秒已是上限区）—— 模型在长段里会自己加戏，宁可多分一段。

### 景别节奏（防止画面发闷）

不要连续三段同景别。推荐循环：

```
中景（交代）→ 近景（情绪）→ 特写（信息）→ 全景（呼吸）→ 中景 …
```

每 3 段至少出现 1 个**特写**和 1 个**带运动镜头的段**。

## 九、转场设计

段与段之间的接法，在分镜表里就标好：

| 转场 | 用法 |
|---|---|
| 硬切 | 默认，节奏快 |
| 动作接动作 | 上一段结尾的手部动作 → 下一段开头同一动作（最关键的一致性手段） |
| 同景别同构图跳切 | 表现时间流逝 |
| 黑场 0.5 秒 | 只用在开场和重大转折 |
| 闪白 | 回忆 / 重生 / 觉醒 |
| 声先入 | 下一段的声音提前 0.5 秒进入——**最便宜的"高级感"** |

**连续性红线**：段间必须对得上 —— 服装、发型、光线方向、道具位置、人物站位、一天中的时间。写分镜表时就要检查，别等生成完才发现。
