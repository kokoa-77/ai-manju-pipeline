# 15 · 商单与交付（MV / PV 定制）

> **一句话定位**：转商业最快见钱的一条路。游戏、虚拟主播、独立歌手、品牌都会买「作曲 + 美术 + AE」一个人包圆的 MV / PV。
> 这份文档管从「有人来问」到「尾款到账 + 作品集更新」的全过程，外加原创资产怎么确权。
> 合同和版权这部分是流程建议，**不是法律意见**；金额大、涉及版权转让的单子，签之前找律师看一眼。

---

## 一、接单前的门槛

先过这几条，再挂「接稿」：

- [ ] 至少 1 支完整代表作 MV + 2–3 支短片（见 `12-同人路线.md` 第八节）
- [ ] 跑过 `log_summary.py`，**知道每种镜头类型的平均工时**，没有这个数就报不准价
- [ ] 作品集里**原创作品**能撑起来：同人作品只能证明手艺，不能拿来商用展示别人的 IP 权利
- [ ] 成品链路的每个模型都核对过商用许可（见 `07-翻车点与模型选型.md` 许可证表）
- [ ] 准备好三份东西：作品集链接、需求确认单（`assets/需求确认单模板.md`）、报价单（`assets/商单报价单模板.md`）

**从哪接**：B站 / 小红书主页挂作品集和接稿说明；二次元约稿平台；直接给中小游戏、虚拟主播运营、独立音乐人发作品集。
主页写清楚：**做什么（MV / PV / 名卡 / 歌词视频）、不做什么、档期、起步价区间**，能挡掉一半无效询单。

## 二、商单流程（6 个停止点）

```
① 询单                → 发需求确认单，让对方填
② 需求确认             → 对方填完的需求确认单            【停止点 1：需求签字】
③ 报价 + 合同 + 定金    → 报价单、合同                    【定金不到不开工】
④ 风格帧 + 分镜表       → 2–3 张风格帧、MV 分镜表          【停止点 2：风格确认】
⑤ 动态分镜（预演）      → 草图 + 音乐拼的 animatic         【停止点 3：节奏确认】
⑥ 制作                 → AE 合成、AI 补位、作曲 / 混音
⑦ 粗剪                 → 带水印低清版                     【停止点 4：粗剪确认】
⑧ 精修                 → 调色、字幕、响度
⑨ 终版                 → 带水印高清版                     【停止点 5：终版确认】
⑩ 尾款 → 交付          → 无水印母版 + 交付包              【停止点 6：尾款到账再交】
⑪ 归档 + 作品集         → 工程打包；按合同约定的时间公开展示
```

**为什么停止点这么多**：MV 最贵的返工是「做完 AE 才发现风格 / 节奏不对」。④⑤两步只花 10–15% 的工时，却能挡掉大部分推翻重来。
每个停止点的确认都要**留文字记录**（聊天截图或邮件），修改轮次从这里开始算。

---

## 三、需求确认（停止点 1）

模板：`assets/需求确认单模板.md`。必须问清的 8 件事：

| # | 问什么 | 为什么 |
|---|---|---|
| 1 | 用途和投放平台 | 决定画幅、时长、响度、授权范围 |
| 2 | 时长 / 画幅 / 版本数 | 16:9 主版 + 9:16 切片是两份活 |
| 3 | 音乐：对方提供 / 你作曲 / 用现成曲 | 作曲是单独一大块工时，也牵扯版权 |
| 4 | 对方提供哪些素材（立绘、Logo、字体、实拍） | 对方要保证这些素材有权给你用 |
| 5 | **能不能用 AI、用在哪些环节** | 很多甲方介意；写进合同，免得交付后扯皮 |
| 6 | 参考片（2–3 支）+ 不要什么 | 比任何形容词都准 |
| 7 | 截止日期 + 中间节点 | 倒推制作周期，排不下就加急价或拒 |
| 8 | 版权：授权使用还是买断；能否进你的作品集 | 直接决定报价倍数 |

**直接拒的单**：要求仿某位在世画师画风、要用别人的同人图或官方素材当主要画面、要克隆真人声音、预算远低于成本还要买断、不签任何书面约定。

## 四、报价

模板：`assets/商单报价单模板.md`。

```
基础价 = 预估工时 × 时薪 + 生成成本 × 1.3 + 外部成本（素材 / 字体授权 / 外包）
报价   = 基础价 × (1 + 修改缓冲 15–20%) × 加急系数 × 版权系数
```

| 系数 | 取值（自己按市场调） |
|---|---|
| 加急系数 | 正常 1.0；制作周期压缩一半 1.3–1.5 |
| 版权系数 | 授权指定平台使用 1.0；不限平台 / 不限期限 1.3–1.5；版权买断 2–3 |
| 作曲 | 单列一项，别混进剪辑工时；原创曲买断另外报 |

**工时从哪来**：`log_summary.py` 的「镜头类型平均工时」× 分镜表里每种类型的镜头数，再加作曲、风格帧、沟通（按总工时 15% 估）。
没有数据之前先别接急单：第一单按估算工时 × 1.5 报，做完用实际数据校准。

**付款节点**（推荐）：

| 节点 | 比例 |
|---|---|
| 签约 | 定金 30–50% |
| 风格帧 + 分镜确认 | 可选中期款 20–30% |
| 终版确认 | 尾款，**到账后才交无水印母版** |

## 五、合同要点（逐条写进去）

| 条款 | 写清楚什么 |
|---|---|
| 交付物 | 版本、时长、画幅、格式清单（直接引用第七节交付规格） |
| 修改次数 | 每个停止点包含 N 轮修改；超出按时薪计费；**已确认的阶段推翻重来算新需求** |
| 付款 | 比例、节点、到账期限；逾期怎么办 |
| 版权归属 | 成品的使用范围（平台、期限、地域、能否二改）；授权还是转让 |
| 原创曲 | 单独约定：只授权本片使用，还是连曲一起买断；你能不能自己发行这首歌 |
| 工程文件 | AE / PR / DAW 工程默认不交；要交另计费 |
| 署名 | 片尾职员表和简介里怎么署你的名 |
| 作品集展示 | 对方公开发布后，你可以在作品集里展示；保密期多长 |
| AI 使用 | 用了哪些 AI 工具、用在哪些环节；对方是否同意；**发布时 AI 标识由谁负责** |
| 素材担保 | 对方提供的素材由对方保证有权使用；你用的素材、字体、模型由你保证可商用 |
| 取消 / 延期 | 对方取消：定金不退，已完成阶段按比例结算；对方延迟反馈：交付日顺延 |
| 验收 | 提交后 N 个工作日不反馈视为确认 |

## 六、制作中的沟通

- **每次只交一个版本**，别给对方「A 版还是 B 版」的选择题，除非在风格帧阶段
- 预览一律**带水印、低清**；终版确认后才出无水印母版
- 反馈收集成一张表：时间码 + 问题 + 改法 + 是否超出轮次。**口头反馈不算数**，让对方文字确认
- 超出轮次的修改，先报价再动手
- 进度每周同步一次，哪怕只有一句话

## 七、交付规格（交付包清单）

| 项 | 默认规格 |
|---|---|
| 母版 | 1920×1080（或合同约定 4K），25fps，H.264 高码率；对方要调色余量时加 ProRes 422 |
| 竖版 | 1080×1920，单独构图，不是横版裁切 |
| 响度 | 音乐向 −9 到 −12 LUFS，剧情向 −14 LUFS，真峰值 ≤ −1 dBTP（见 `13-拼贴风MV.md` 第九节） |
| 字幕 | 有字版 + 无字版各一份；SRT 单独给（`make_srt.py` 导出） |
| 音频分轨 | 合同约定时给：人声 / 伴奏 / 音效 三轨 WAV |
| 封面 | 横版 + 竖版各一张，无文字版一张 |
| 文件命名 | `<客户>_<项目>_<版本>_<画幅>_<日期>.mp4`，例 `某工作室_周年PV_终版_16x9_20261010.mp4` |
| 说明文档 | 版本清单、规格、AI 使用说明、署名信息 |

交付前按 `13-拼贴风MV.md` 第十二节的验收清单打一遍钩。

## 八、归档与作品集

- 工程按 `14-AE合成技法.md` 的「整理工程」打包，和交付包一起存两份（本地 + 网盘 / 硬盘）
- 生成日志照常填，商单的工时数据最值钱：下次报价就靠它
- 作品集按合同约定的时间公开；每个案例写：客户类型、需求、你负责的环节、用时
- 每接 3 单复盘一次：哪类单利润最高、哪个环节总超工时，调整时薪和接单范围

## 九、原创资产确权（转原创 IP 之前做）

同人期的作品不涉及这一节；**原创曲、原创角色、原创 IP** 要开始积累权属证据。

| 资产 | 怎么做 |
|---|---|
| 原创曲 | 发行到音乐平台的原创音乐人计划（获得原创认证、版权保护和收益）；重要作品可做作品著作权登记 |
| 原创角色设定 | 定稿后做美术作品登记（自愿登记，费用和流程以版权保护中心 / 各省版权局为准） |
| 创作过程 | **保留手稿 PSD、DAW 工程、AE 工程、带日期的过程截图**：出现权属争议时，这是你「人的创作投入」的证据 |
| IP 名称 | 准备做周边或授权给别人时，再考虑注册商标 |

**AI 生成部分的版权**：目前司法实践倾向于看「人的独创性投入」——提示词设计、反复筛选修改、手绘和合成占比越高，越容易主张权利；纯 AI 直出的画面能不能受保护还不确定。所以：

- 原创 IP 的**角色设定、关键视觉尽量自己画**，AI 只做辅助
- 用于原创 IP 的模型必须允许商用，且你拥有输出的使用权（逐个读平台条款）
- 训练原创角色 LoRA 的数据只用你自己画的图

具体规定以届时的法律法规、平台条款和官方公告为准。
