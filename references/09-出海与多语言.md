# 09 · 出海与多语言

> Seedance 2.5 **原生支持 10+ 语言**，而且音色特征与语言无关。
> 这意味着：**同一批画面资产 + 一份中文音色样本，可以低成本产出多语版本。**
> 但"翻译一下"不等于出海，真正的成本在文化改编。

---

## 一、好消息：音色可以跨语种复用

**机制**：Seedance 提的是**音色特征**（声线、气声、共鸣位置），不是发音。
所以一段 5–15 秒的中文音色样本，可以驱动英文、日文、西班牙文台词，出来还是"同一个人的声音"。

**这直接改变了出海成本结构**：

| | 传统做法 | Seedance 2.5 做法 |
|---|---|---|
| 英语版 | 找英语配音演员重录 | 复用中文音色样本 + 英文台词 |
| 日语版 | 找日语配音演员重录 | 同上 |
| 成本 | 语言数 × 配音费 | **≈ 0 增量**（只多跑几次生成） |

⚠️ 但**参考音频本身别串味**：样本里不能有中文咬字的习惯性语调痕迹太重，否则英文台词会带口音。
录样本时用**中性、平稳**的语气读，不要用情绪化的台词。

---

## 二、台词语言加固写法（必须写）

**只写 `{台词}` 不写语言，模型会飘。** 官方推荐的加固写法：

```text
台词语言：美式英语。女孩用自然、口语化的美式英语说：{I'm not the girl you left behind.}
```

结构拆解：
1. **先声明语言**：`台词语言：美式英语。`（或 `Japanese` / `Latin American Spanish` / `Brazilian Portuguese`）
2. **再声明口音/语域**：`自然、口语化的` / `正式的商务口吻` / `街头俚语`
3. **最后才是 `{台词}`**

### 语言对照表（写 prompt 时直接抄）

| 目标市场 | prompt 里写 |
|---|---|
| 北美 | `台词语言：美式英语。`（不要只写 English，会飘成英音） |
| 英国/澳洲 | `台词语言：英式英语。` |
| 日本 | `台词语言：日语。` |
| 韩国 | `台词语言：韩语。` |
| 东南亚（印尼） | `台词语言：印尼语。` |
| 拉美 | `台词语言：拉丁美洲西班牙语。`（不要写 Spanish，会飘成西班牙口音） |
| 巴西 | `台词语言：巴西葡萄牙语。` |
| 中东 | `台词语言：阿拉伯语。` |

### ⚠️ 三条硬规则

1. **一条生成里，所有台词必须是同一语言。** 中英混用会出错 —— 这是官方明确的限制。
   要双语版就**跑两条**，别在一条里混。
2. **符号系统不变**：台词仍然用 `{}` 包起来。语言声明写在 `{}` **外面**。
3. **否定约束要重申**：`不要字幕` —— 出海时模型更容易自作主张加英文字幕。

---

## 三、多语版的三种产出路线

### 路线 A：重新生成（推荐给新片）

同一个分镜表，同一条提示词，**只改语言声明和 `{}` 里的台词**，跑第二条。

- ✅ 口型是对应语言的（这是关键，中文口型配英文音轨会非常违和）
- ✅ 音色一致
- ❌ 要重跑一遍生成，成本 = 一次生成量

**适用**：正式出海发行。口型对不上是出海片最大的廉价感来源。

### 路线 B：只换音轨（推荐给试水）

保留中文版视频，用剪映/PR 把音轨替换成配音版。

- ✅ 成本极低
- ❌ **口型对不上** —— 观众一眼看出来
- ❌ 只适合"先看看这个市场有没有反应"的试水

**适用**：先花小钱验证市场，别一上来就重做。

### 路线 C：混合（推荐给正式发行）

- **有台词的段** → 路线 A 重跑（要口型）
- **过场段 / 空镜段 / 无台词段** → 直接复用中文版

**适用**：**性价比最高**。一集里真正有台词的段通常只占 40–60%。

---

## 四、字幕与本地化素材

### 4.1 字幕

- **不要让模型把字幕画进画面**（`不要字幕` 必须写）—— 出海多语时更要强调
- 字幕用剪映的字幕轨，导出**无字幕母版**，再按语言挂字幕文件
- 竖屏短剧的字幕位置：**底部安全区内，距底 15% – 20%**（避开平台 UI 遮挡）

### 4.2 全片要重做的物料

| 物料 | 要不要重做 | 说明 |
|---|---|---|
| 封面图 | ✅ 重做 | 封面上的文字必须换语言 |
| 标题 | ✅ 重做 | 不是翻译，要按目标市场的爆款句式重写 |
| 简介 | ✅ 重做 | 关键词要按当地搜索习惯 |
| 话题标签 | ✅ 重做 | 用当地平台的流行 tag，别直接译中文 tag |
| 片尾标识 | ✅ 重做 | AI 生成标识也要用当地语言 |

## 五、文化改编（真正的成本在这）

**翻译 ≠ 出海。** 下面这些直接翻译出去会翻车：

| 中文原设定 | 直接翻译的问题 | 改法 |
|---|---|---|
| 家族企业继承权 | 欧美观众对"家族企业"共情弱 | 改成 **遗产争夺 / 信托基金** |
| 彩礼、婆媳 | 完全无共鸣 | 改成 **婚前协议 / 继母关系** |
| 高考、复读 | 无共鸣 | 改成 **大学录取 / 奖学金** |
| 酒桌文化、敬酒 | 不理解"敬酒的羞辱感" | 改成 **公开场合的社交压制** |
| 微信截图、朋友圈 | 不认识 | 改成 **短信 / 社媒私信** |
| 古装、仙侠 | 门槛高，但**有固定受众** | 保留，但要求画风更"东方奇幻"而非"历史考据" |

### 出海友好度排序（女频复仇为例）

1. **豪门/财阀斗争** —— 最通用，只需要换身份名称
2. **职场复仇** —— 通用
3. **重生复仇** —— 通用（"重生"概念在东亚外也有市场）
4. **婚恋背叛** —— 通用
5. **宫斗/宅斗** —— 需要较多改编，但东南亚接受度高
6. **仙侠/玄幻** —— 门槛最高，但一旦接受就极忠诚

## 六、平台差异

| 平台 | 主市场 | 时长适配 | 注意 |
|---|---|---|---|
| TikTok | 全球 | 60–90 秒 | 语速要更快，前 3 秒更狠 |
| YouTube Shorts | 全球 | ≤60 秒 | 完播率权重高 |
| Instagram Reels | 欧美 | 60–90 秒 | 审美要求更高，画质别糊 |
| 东南亚本地平台 | SEA | 60–120 秒 | 节奏可以慢一点 |

**一条通用规律**：海外版**开头要更快**。
中文版黄金前 6 秒的钩子，出海版建议**压到 3–4 秒**。

---

## 七、合规（比国内更严）

- **AI 生成内容标识**：欧盟 AI Act、YouTube、TikTok 都要求标注，**且要用当地语言**
- **版权音乐**：BGM 千万别用中文平台的热门曲，出海必被下架。用平台自带曲库
- **人像与肖像**：欧美对真人肖像权更敏感，**恰好 AIGC 是优势**（不涉及真人）
- **未成年人 / 暴力**：欧美平台对"校园暴力""霸凌"题材限制更紧

## 八、出海版开工清单

- [ ] 目标市场定了（一个国家，别一次铺三个）
- [ ] 分镜表已标注**哪些段有台词**（决定走路线 A 还是 C）
- [ ] 台词已按目标语言**重写**（不是翻译）
- [ ] 每条提示词都加了 `台词语言：xxx。` 声明
- [ ] 一条生成内**没有混用语言**
- [ ] 音色样本语气中性（不带中文语调痕迹）
- [ ] 封面/标题/简介/标签全部按当地重做
- [ ] 无字幕母版已导出
- [ ] AI 标识用当地语言写好
- [ ] BGM 换成平台曲库
