# 10 · 真人短剧变体

> 主流程（`01`–`07`）默认走**漫剧/动画**画风。本文只讲**改成真人写实风**时要动哪些地方。
> 真人风 ≠ 真人拍摄，不需要演员。它是让 Seedance 输出"看起来像实拍"的画面。
> **流程骨架完全一样**，改的是资产标准、摄影语言、抽卡预算和合规。

---

## 一、先决定：这个题材该用漫剧风还是真人风

| 题材 | 建议画风 | 原因 |
|---|---|---|
| 玄幻 / 仙侠 / 异能 | **漫剧风** | 特效和夸张表演在写实里很违和 |
| 沙雕日常 | **漫剧风** | 表情可以夸张，真人风会尴尬 |
| 都市复仇 / 职场 | **真人风** | 观众代入感强，广告主认 |
| 豪门 / 财阀 | **真人风** | 服化道质感是卖点 |
| 婚恋 / 情感 | **真人风** | 微表情是核心 |
| 穿越 / 系统流 | 看落点：古代→漫剧，现代→真人 |

**一句话**：**要"爽"用漫剧，要"扎心"用真人。**

---

## 二、资产标准变了（这是最大的改动）

### 2.1 角色三视图：要求更高

漫剧风的三视图**允许简化**（平涂、线稿感）。
真人风的三视图**必须包含皮肤纹理和真实光影**，否则 Seedance 会自由发挥，脸就飘了。

真人风三视图出图提示词要加：

```text
真实皮肤质感（可见毛孔、细纹、自然高光），photorealistic，
单反拍摄，85mm 定焦，f/2.0 浅景深，
正面均匀柔光 + 侧后方轮廓光，
白底 #FFFFFF，无阴影
```

### 2.2 资产清单要多三样

| 多出来的资产 | 为什么真人风必须要 |
|---|---|
| **手部特写参考图** | 真人风的手最容易崩（六指、融指），漫剧风一笔带过看不出来 |
| **发型侧面 + 背面细节图** | 真人发丝的分组、走向要一致 |
| **服装材质特写** | 丝绸/羊绒/皮革的反光不同，材质错了立刻假 |

### 2.3 表情状态图要更多

漫剧风靠"符号化表情"（眼泪、汗滴）传递情绪；
真人风**只能靠微表情**，所以每个情绪状态都要单独出参考图：

`落泪` `强忍` `冷笑` `瞳孔收缩` `嘴角抽动` `失神` —— 一到两集就要 6–10 张。

---

## 三、提示词：加一层"摄影语言"

真人风的核心差别是：**画面要像被一台摄影机拍下来的，不是被画出来的。**

### 3.1 摄影语言词库（直接抄用）

| 类别 | 词 |
|---|---|
| **焦段** | 24mm 广角（空间压迫）· 35mm（纪实感）· 50mm（标准/客观）· 85mm 定焦（人像/柔美）· 135mm（压缩/窥视感） |
| **光圈/景深** | f/1.4（极浅景深，背景化开）· f/2.8（人像常用）· f/8（全清晰，纪实） |
| **胶片/数码** | 胶片颗粒感 · Kodak Portra 色调 · 数码锐利 · ARRI Alexa 高宽容度 |
| **机位** | 肩扛手持 · 三脚架固定 · 斯坦尼康稳定跟随 · 云台平滑横移 |
| **灯光** | 三点布光 · 蝴蝶光（鼻下蝴蝶形阴影）· 伦勃朗光（侧 45° 三角光）· 轮廓光（勾边）· 实用光源（烛火/台灯本身入画） |
| **质感** | 轻微镜头呼吸 · 轻微失焦 · 浅景深光斑 · 自然高光过曝 |

### 3.2 漫剧风 vs 真人风的 prompt 对照

**同一个镜头，两种写法：**

```text
【漫剧风】
3s-6s：特写，缓慢推近。林晚的眼睫轻颤一下，睫毛投下细影。
眼睫轻颤，喉结吞咽一次，手指收拢握紧杯脚。<杯壁与指尖摩擦的细响>

【真人风】
3s-6s：特写，85mm 定焦，f/2.0 浅景深，缓慢推近。林晚的眼睫轻颤一下，
背景烛台化开成暖色光斑，皮肤可见细微毛孔与自然高光。
眼睫轻颤，喉结吞咽一次，手指收拢握紧杯脚，手背青筋微凸。<杯壁与指尖摩擦的细响>
```

**差别就三处**：加焦段光圈、加皮肤/光学细节、加背景处理。

### 3.3 真人风必写的否定约束（补充）

在主流程的 `不要字幕 / 不要背景音乐` 之外，真人风还要加：

```text
不要塑料感皮肤；不要过度磨皮；不要蜡像质感；不要塑料光滑；
不要多余手指；不要扭曲的手部；不要死板的眼神；
不要游戏 CG 感；不要 3D 渲染感
```

⚠️ **"过度磨皮"是真人风头号杀手。** 不写这句，出来的脸会像蜡像，观众第一眼就出戏。

## 四、抽卡预算要上调

真人风的容错率**远低于**漫剧风：

| 场景 | 漫剧风预计次数 | **真人风预计次数** |
|---|---|---|
| 单人无台词 | 2–3 | **3–5** |
| 单人带台词 | 3–5 | **5–8** |
| 双人 | 4–6 | **6–10** |
| 多人 | 6–10 | **10–15** |
| 复杂运镜 | 5–8 | **8–12** |
| 开场/结尾 | 8–10 | **10–15** |

**原因**：漫剧风的"小瑕疵"（手有点怪、光影不连贯）在风格化下被接受；
真人风里同样的瑕疵会触发**恐怖谷效应** —— 观众说不出哪里怪，但就是觉得假。

**真人风的废片判定更严格**：
- 漫剧风：一处小问题 → 定点修
- **真人风：手部/眼睛/牙齿任何一处不对 → 直接重抽**（定点修容易越修越怪）

## 五、出图模型选型变了

| 环节 | 漫剧风 | **真人风** |
|---|---|---|
| 三视图定稿 | Seedream 5.0 Pro | **Nano Banana Pro**（写实摄影最强） |
| 需要分层/定点改 | Seedream 5.0 Pro | Seedream 5.0 Pro |
| 本地草稿 | Z-Image Turbo | Z-Image Turbo（但写实能力弱，只用来试构图） |
| 带文字物料 | 任意旗舰 | 任意旗舰 |

**关键**：真人风的定稿**必须用写实能力最强的模型**。
Seedream 5.0 Pro 在漫剧/插画上很强，但真人皮肤质感不如 Nano Banana Pro。

---

## 六、声音层要更讲究

真人风观众对声音更敏感：

- **气息声要留**：真人说话有吸气、气口、轻微的唇齿声。全剪干净会像配音棚念稿
- **不要"播音腔"**：音色样本要选**口语化**的，不是新闻播报式的
- **环境声要有**：真人风画面 + 干净音轨 = 违和。宴会厅就该有宴会厅的底噪
- **台词密度要降**：真人风里"字正腔圆"会假。台词密度从 5 字/秒 降到 **4–4.5 字/秒**，留出停顿和呼吸

---

## 七、合规：真人风更严

| 风险 | 说明 | 处理 |
|---|---|---|
| **深度伪造判定** | 真人风 + 逼真脸 → 平台更可能要求标注或限流 | 片头或简介明确写"AI 生成，非真人出演" |
| **肖像权** | 如果角色长得像某个真实明星 → 侵权风险 | 角色设计时**刻意避开知名面孔特征** |
| **真人素材参考** | 用真人照片当参考图 → 肖像权问题 | **只用 AI 生成的参考图**，不要拿真人照片喂 |
| **"非真人出演"声明** | 部分平台强制要求 | 简介 + 片尾都写 |

⚠️ **绝对不要用明星/网红的照片当角色参考图。** 这是出海和国内都会直接封号的红线。
