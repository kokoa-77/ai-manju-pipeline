# ③ 资产层 · 角色圣经与素材编号

**这一层是全流程唯一"必须一次做对"的环节。** 前三集省下的资产工作，会在第 10 集变成 20 倍的返工。

---

## 一、为什么必须生图（给用户的解释话术）

> Seedance 2.5 的参考图上限是 30 张，但**官方推荐稳定区只有 1–8 个主体**。你上传的角色图就是模型的"外观锚点"——它靠这个锚点把脸锁住，**不是靠文字描述锁**。文字写"圆脸桃花眼"十遍，不如一张三视图。
>
> 只用文字：第 1 集和第 25 集的女主不是同一个人。模型每次重新"想象"这张脸。

**参考图 ≠ 首帧图**：
- 老流程：图片当**首帧**（I2V），构图被钉死，只覆盖这一个镜头
- 新流程：图片当**参考**（R2V），模型理解"这人的五官/发型/服装"，然后按提示词自由调度运镜 —— 一条 30 秒里能换好几个机位，人还是同一个人

## 二、角色圣经（每个主要角色一份）

### 必须锁死（一个字都不改）

| 字段 | 说明 | 例子 |
|---|---|---|
| 角色名 | 全片统一 | 林晚 |
| **几何原型** | 圆 / 方 / 三角 | 圆形 |
| 脸型 | 具体到骨相 | 鹅蛋圆脸，下颌线柔和中带韧 |
| 肤色 | | 冷白皮 |
| 发型 | 长度+分缝+质感 | 黑长直中分，及胸 |
| 眼型 | | 眼尾微垂，双眼皮窄 |
| 唇 | | 唇色偏冷，唇形不厚 |
| 身形 | | 纤细，肩窄 |
| 标志特征 | 观众认人的锚点 | 左手腕细银链 |
| 常态服装 | 试播期固定一套 | 酒红丝绒长裙 |
| 音色关键词 | 描述给配音/参考用 | 偏低、语速慢、尾音不上扬 |

### 可以变（写清变体，别临时改）

- 表情状态：落泪 / 受伤 / 暴怒 / 微醺
- 特殊服装：换装集、年代闪回
- 发型变化：盘发 / 散开（剧情需要时才用）

**变更协议**：任何锁死字段要改，先新建 `v2` 资产并更新编号表，**不要原地覆盖 v1**。编号表可以加「启用集 / 停用集」两列，写清 v2 从第几集起生效，旧集返工时才知道该用哪一版。

## 三、几何语言（前置于工具）

用 **圆 / 方 / 三角** 三种基础形状统一控制脸型、体型、局部特征：

| 原型 | 用在哪 | 视觉语言 |
|---|---|---|
| **圆** | 主角、憨角、被欺负的人 | 亲和、无害、值得同情 |
| **方** | 稳重角色、长辈、执法者 | 可靠、克制、有分量 |
| **三角**（尖） | 反派、攻击性角色、竞争者 | 锐利、压迫、危险 |

**观众在看到脸之前就已经"读懂"了角色。** 写角色圣经时先定原型，再填五官细节。

## 四、资产最小集

| 资产 | 试播集（1 集） | 正式集（每新增 1 集） | 系列级（做一次，全集复用） |
|---|---|---|---|
| 角色三视图（正面/侧面/背面，白底） | 每主要角色 1 张 | — | ✅ 系列级 |
| 角色定妆图（正面半身，白底） | 每主要角色 1 张 | — | ✅ |
| 表情/状态图 | 按需 2–4 张 | 按需追加 | 部分 |
| 场景空镜（无人） | 每场景 1 张 | 新场景才做 | 部分 |
| 道具产品图（白底） | 关键道具 | 新道具才做 | 部分 |
| 音色参考（5–15 秒） | 每角色 1 段 | — | ✅ 系列级 |

**新角色出场的判断线**：有台词 → 必须做三视图 + 音色。只露脸不说话 → 做定妆图即可。

## 五、★ 全局素材编号表（最容易翻车的地方）

文件：`02_资产/_素材编号表.csv`

| 列 | 说明 |
|---|---|
| 编号 | 图片1、图片2……（对应提示词里的 `@图片N`） |
| 文件 | 相对路径 |
| 主体 | 角色名 / 场景名 / 道具名 |
| 类型 | 三视图 / 定妆 / 表情 / 空镜 / 白底 |
| 用途 | 一句话，会被抄进提示词的"素材指代"段 |
| 不采用 | 明确排除什么（图片背景 / 图中人物 / 服装） |

**规则：两层编号，别混**

| 层 | 是什么 | 谁维护 |
|---|---|---|
| **编号表编号**（如 `图片6`） | 全局资产 ID，管理用 | 你，在 `_素材编号表.csv` 里 |
| **提示词槽位**（如 `@图片2`） | 这一条生成里第几张上传的图 | `build_prompts.py` 自动换算 |

即梦里的 `@图片1` 指的是**这一次上传的第 1 张图**，它不会去查你的编号表。所以：

1. 编号表编号**全局唯一，一旦分配永不变更**；新资产追加，不复用废号
2. 分镜表「参考素材」列写**编号表编号**
3. 提示词里写**槽位号**，每条生成从 1 开始；脚本会输出「上传清单」告诉你第几个传哪个文件
4. 上传顺序：**图片 → 视频 → 音频**，音色永远排在所有画面素材之后
5. 手写提示词时也按这个规矩：先列上传清单，再按清单写 `@图片N`

素材指代句固定写法：

```
@图片3用于林晚的五官、发型和酒红丝绒长裙，不采用图片背景。
@图片7用于婚礼彩排厅的空间布局、材质和光线，不采用图中人物。
@图片9用于银色项链的造型与材质，纯白背景可直接抠图。
@音频1作为林晚的配音音色参考。
```

## 六、出图提示词模板

### 三视图（最重要的一张）

```
角色三视图设定稿，纯白背景 #FFFFFF，均匀柔光无阴影。
<年龄>岁<性别>，<脸型>，<肤色>，<发型>，<眼型>，<唇>，<身形>，
穿着<服装描述>，<配饰>。
同一角色的正面、侧面、背面三个视角并排站立，比例一致、身高一致，
五官与发型在每个视角中完全一致，服装无变化。
无背景、无文字、无边框、无多余元素。
电影级3D写实渲染，8K超高清，角色设定图风格。
```

> **三视图出图和上传是两回事**：出图时三个视角拼在一张设定稿上，方便你检查比例、存档；**上传给 Seedance 时裁成三张单视角图**（见第七节「一张图放一个视角」），正面那张最重要，通常只传正面就够。
> 2D / 二次元项目：把最后一行「电影级3D写实渲染」换成系列圣经里的 2D 风格锁定字段（见 `13-拼贴风MV.md`）。

### 定妆图（半身）

```
<角色名>角色定妆照，正面半身，平视。纯白背景 #FFFFFF，正面均匀柔光无阴影。
<锁死字段照抄>。神情<克制/警惕/坦然>，不看镜头。
无文字、无背景元素。电影级3D写实渲染，8K超高清。
```

### 表情/状态图

```
<角色名>角色表情设定，正面近景特写。<锁死字段照抄>。
状态：<落泪 / 左颊擦伤 / 强忍怒意 / 微醺>。
只改神情和皮肤状态，五官、发型、服装与三视图完全一致。
纯白背景，均匀柔光。无文字。8K。
```

### 场景空镜（无人）

```
无人场景空镜。<场景描述>。
<主光源>投下<光质>并形成<光斑/阴影>，<主色调>为主色调，<次色调>为次色调，
<点缀色>作为点缀。无人、无文字、无字幕、无人物剪影。
<光质描述>，低调暗部与明亮高光对比。
UE5引擎3D写实渲染，8K超高清，电影级质感。
```

### 道具产品图

```
<物品名>产品摄影，<形体描述>，<材质细节>，
纯白背景 #FFFFFF，正面均匀柔光无阴影，

```

## 七、多视角的坑（官方明确）

**同一主体要多个视角时，一张图放一个视角，别把几个视角拼成一张拼贴图** —— 拼图会掉稳定性。

同理，**别只在参考图上贴文字标签**（写"这是正面"），模型会把它当画面内容。

## 八、生成工具路线

| 路线 | 工具 | 适用 |
|---|---|---|
| **主力（推荐）** | **Seedream 5.0 Pro**（即梦） | 与 Seedance 2.5 同厂同平台，资产直接复用；区域编辑强；主体保持好；原生 4K；中文渲染强 |
| 特效药 | Nano Banana Pro（Google `gemini-3-pro-image`） | 写实质感不够 / 要往图里排中文字 / 参考图 >10 张 / 要 4K |
| 成本敏感 | GPT Image 1.5 / Seedream 5.0 Lite | 大批量草稿 |
| **本地免费** | **ComfyUI + Z-Image-Turbo（INT8）** | 资产量大、想省 token。见 `07-翻车点与模型选型.md` 附录 |

**注意**：DSH 会话内置出图工具能直接产出 PNG，可用来**出草案和确认方向**；定稿建议用 Seedream 5.0 Pro 重出（白底更干净、主体保持更稳）。

### 出图后的自检（三视图）

- [ ] 三个视角是同一个人（不是三个长得像的人）
- [ ] 身高、肩宽、比例一致
- [ ] 发型在背面视角是对的
- [ ] 服装无变化，配饰位置一致
- [ ] 背景是纯白，没有阴影和杂物
- [ ] 画面里没有任何文字
