# 13 · 拼贴风 MV（实拍 + 手绘 + 拼贴设计 + AI 补位）

> **一句话定位**：参考游戏官方宣传 MV 那种「实拍里住着 Q 版角色、手账拼贴、手写字、一首歌撑起 3–4 分钟」的风格。
> 主要靠设计和合成，AI 只在背景、高潮作画镜头和素材生成上补位。人工比重高，二次元圈接受度也高；
> 这也正是游戏公司、虚拟主播、独立歌手会花钱定制的内容。

---

## 一、风格 DNA

1. **真实世界 × 二次元**：实拍的咖啡店、公路、海边、车窗，里面「住着」带白边的 Q 版角色
2. **手作感**：手写字、荧光笔涂鸦、纸张胶带、贴纸、星星和小图标，像一本会动的手账
3. **一个主题色系贯穿全片**：例如橙 + 天空青 + 奶油白
4. **两种比例混用**：Q 版（日常、轻松段）+ 正常比例（情绪高潮段）
5. **歌词是设计元素**：宽银幕黑边里的细衬线小字，或手写大字的动态排版
6. **结构跟歌走**：主歌日常拼贴，副歌上大镜头，结尾手写信 + 职员表

**参考数据**（几支同类官方 MV / PV 的实测）：时长 3:45–4:01；帧率 25fps；平均每 1–2.3 秒切一次镜头；响度 −7 到 −13 LUFS（按音乐母带做得偏响）。

## 三、镜头类型库（12 种）

所有分镜都从这张表选。MV 分镜表的「镜头类型」列填编号，`scripts/check_mv_shots.py` 会按编号统计。
**「AI 参与」越低，越能体现你的手艺。**

| # | 镜头类型 | 怎么做 | AI 参与 | 难度 |
|---|---|---|---|---|
| 1 | **实拍空镜 + Q 版贴纸角色** | 手机拍空镜 → 画 Q 版透明 PNG → AE 摄像机跟踪贴进去 → 白边、投影、小动作 | 低 | ★★ |
| 2 | **周边实拍** | 拍你自己的亚克力立牌、毛绒、谷子，浅景深、自然光 | 无 | ★ |
| 3 | **手账拼贴转场** | 纸张、胶带、贴纸、涂鸦在 AE 里逐层飞入、撕开、翻页 | 低（素材可 AI 生成） | ★★ |
| 4 | **手写大字标题 / 角色名卡** | 你手写 → 矢量化 → AE 书写动画 + 弹性缩放 | 无 | ★★ |
| 5 | **剪影色块** | 角色剪影填纯色块，配图案底纹，卡点切换 | 无 | ★ |
| 6 | **2.5D 场景 + 2D 角色** | 场景图（AI 或手绘）拆前中远景 → AE 3D 摄像机推拉 → 角色层放进去 | 中 | ★★★ |
| 7 | **高潮作画镜头** | 关键帧 → MiniMax H3 试错 → Seedance 2.5 定稿 → 超分 | 高 | ★★★ |
| 8 | **Q 版扁平动画段** | 剪纸感 Q 版角色，AE 操控点做简单动作 | 低 | ★★ |
| 9 | **宫格蒙太奇** | 2×2 / 3×3 宫格，卡点快速换实拍或插画 | 无 | ★ |
| 10 | **画中画 + 侧边文字** | 黑底，画面缩成窗口，旁边滚动注释或台词 | 无 | ★ |
| 11 | **宽银幕 + 细衬线歌词** | 上下黑边，歌词放在黑边里，小字号、宽字距 | 无 | ★ |
| 12 | **手写信 + 职员表结尾** | 横线信纸上手写字逐行出现；职员表跟尾奏滚动 | 无 | ★ |

**一首 3–4 分钟 MV 的典型配比**：

| 歌曲段落 | 主要镜头类型 |
|---|---|
| 前奏 | 4 手写标题 / 2 周边实拍 / 11 宽银幕 |
| 主歌 | 1 实拍 + 贴纸、2 周边、8 Q 版扁平、9 宫格 |
| 预副歌 | 3 拼贴转场、5 剪影色块，节奏加快 |
| 副歌 | 6 2.5D 场景、7 高潮作画、群像 |
| 间奏 / 桥段 | 10 画中画、9 宫格，节奏放慢或回忆感 |
| 最后副歌 | 7 作画 + 3 拼贴混剪，全片最密 |
| 尾奏 | 12 手写信 + 职员表 |

**AI 作画镜头（类型 7）建议不超过全片时长的 40%**，超了 `check_mv_shots.py` 会警告：成本和崩坏风险都高，能用 AE 分层做的镜头不进视频模型。

## 四、MV 分镜表

模板：`assets/MV分镜表模板.csv`。

```
段号,歌曲段落,小节,拍点时间,时长,镜头类型,画面内容,素材来源,AI工具,歌词,备注
s01,前奏,1-2,0.0-3.8,3.8,4,手写标题逐笔写出,手写,无,,纸张底纹
s02,前奏,3-4,3.8-7.6,3.8,1,海边防波堤右移；Q版角色坐在栏杆上晃腿,实拍+Q版,无,,白边4px
s03,主歌A,5,7.6-9.5,1.9,2,亚克力立牌浅景深特写,实拍,无,I get to see a smile again|又能看见你的笑容,
```

- **先作曲，后分镜**：在 DAW 里标好小节线和拍点，镜头切点对齐重拍
- `小节` 写 `5` / `1-2` / `5.3`（第 5 小节第 3 拍）/ `7.3-8`；**只填小节，`拍点时间` 和 `时长` 交给 `beat_grid.py` 算**
- `拍点时间` 写绝对时间：`7.6-9.5` 或 `0:07.6-0:09.5`；相邻镜头首尾要接上
- `歌词` 用 `|` 分行，可以做双语
- 每个镜头一般 2–5 秒

```bash
# 按 BPM 把「小节」换成拍点时间（前奏前有空白就填 --offset，中途变速用 --change 小节:BPM）
python scripts/beat_grid.py --bpm 120 --offset 0.5 --shots 01_脚本/01_MV分镜表.csv --out 01_脚本/01_MV分镜表.csv

# 体检：空档 / 重叠 / 镜头类型 / AI 占比 / 各段落节奏
python scripts/check_mv_shots.py --shots 01_脚本/01_MV分镜表.csv

# 歌词直接导出 SRT，导进 PR
python scripts/make_srt.py --shots 01_脚本/01_MV分镜表.csv --out 01_歌词.srt
```

## 五、动态分镜（预演）：进 AE 之前先拼一版

分镜表写完、素材还没做之前，**先在 PR 里用草图把整首歌拼一遍**。AE 合成是最贵的工时，节奏不对在这一步改只要几分钟，做完 AE 再改要几天。

```bash
# 小节号字幕：导进 PR 当字幕轨，时间线上直接看到第几小节、哪个段落
python scripts/beat_grid.py --bpm 120 --offset 0.5 --shots 01_脚本/01_MV分镜表.csv --srt 01_脚本/01_小节.srt
```

| 步骤 | 做法 |
|---|---|
| 1 | PR 新建 1920×1080 25fps 序列，放原创曲 + 小节字幕轨 |
| 2 | 每个镜头放一张图：手绘草图 / 实拍截图 / 风格帧 / 素材库里的旧图都行，**不用好看** |
| 3 | 按分镜表的拍点时间切，加最简单的推拉和文字（「这里 Q 版跳出来」） |
| 4 | 歌词用 `make_srt.py` 导出的 SRT 直接放上去 |
| 5 | 全片完整看 3 遍：有没有拖、副歌够不够炸、同类型镜头是不是扎堆 |
| 6 | 改分镜表 → 重跑 `beat_grid.py` + `check_mv_shots.py` → 再拼一版 |

**停止点**：动态分镜确认后才开始画素材、拍实拍、做 AE。商单里这一步要给客户看（见 `15-商单与交付.md`）。
动态分镜放 `06_工程/PR/`，命名 `<系列名>_动态分镜_v1.prproj`；之后每个镜头做完就替换掉对应草图，它直接变成正式剪辑工程。

## 七、实拍规范

| 项 | 规范 |
|---|---|
| 设备 | 手机就够：4K 25fps；锁定曝光和白平衡 |
| 慢动作 | 想做慢动作的镜头（海浪、头发、花瓣、水花）用 **50fps** 拍，在 25fps 时间线上正好 2 倍慢放；不要用 60fps，在 50Hz 灯光下容易闪 |
| 运镜 | 慢推、慢移、固定；画面要有前景和纹理，方便 AE 跟踪 |
| 构图 | **给 Q 版角色留位置**：拍的时候就想好她站在哪 |
| 时长 | 每段 10 秒以上，剪的时候有余量 |
| 光线 | 清晨、黄昏的自然光最出片；室内注意灯光频闪 |
| 周边拍摄 | 自然光、浅景深（人像模式或微距），背景干净 |
| 隐私 | 路人正脸不入镜或虚化；店内拍摄先征得同意；车牌、门牌打码 |

拍不到的场景（沙漠公路、海上平台）用 Z-Image / Seedream 生成，或用 MiniMax H3 让一张场景图动起来。

## 八、帧率：25fps，不用 60fps

- 二次元的番剧感来自低帧率（一拍二、一拍三），60fps 会像游戏录屏
- AI 视频模型原生约 24fps，补到 60fps 要插帧，2D 线条容易拖影、融化
- AE 渲染时间和文件体积都会变成约 2.4 倍
- 国内照明是 50Hz，25fps 拍室内不容易闪
- 60fps 只适合游戏录屏、舞蹈 / 节奏游戏、快速滚动的 UI 动效

## 九、音乐与响度

| 资产 | 用途 |
|---|---|
| MV 主曲（完整版） | 代表作 |
| 30–60 秒可剪版本 | 切片、预告 |
| 情绪 BGM 5–8 段 | 小剧场、幕后视频 |
| 标志音 2–3 个 | 片头、转场，账号辨识度 |

- 不用原作 OST、不用流行歌；保留分轨，方便为画面改编曲
- **响度**：音乐向 MV 按音乐母带标准，约 −9 到 −12 LUFS；有台词的小剧场约 −14 LUFS；**真峰值都不超过 −1 dBTP**。平台可能做音量均衡，太响反而被压；参考作品里有削波，不要学

## 十、单条流程

```
① 企划卡（assets/企划卡模板.md）：主攻镜头、歌曲段落、预算上限
② 音乐段落定稿 → DAW 标小节 / 拍点，记下 BPM 和第 1 小节起点
③ MV 分镜表：填小节和镜头类型 → beat_grid.py 算拍点时间 → check_mv_shots.py 体检
④ 动态分镜：草图 + 音乐 + 小节字幕拼一版（第五节）          【停止点：节奏确认】
⑤ 素材：实拍 / 手绘 / AI 生成（只生成真正缺的）
⑥ AE 逐镜头合成（套素材库模板，技法见 14），做完一个替换一个草图
⑦ PR 组装 + make_srt.py 导出歌词 + 调色 + 响度           【停止点：粗剪确认】
⑧ 按下面的验收清单打钩 → 封面、标题、简介、AI 标识
⑨ 发布 → 48 小时填数据表 → 复盘一处问题；生成日志跑 log_summary.py
```
