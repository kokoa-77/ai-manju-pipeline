# ⑧ 剪辑收尾 · 发布 · 数据回收

> **剪辑软件怎么选**：漫剧跑量、竖屏、要快 → 剪映；同人 MV、拼贴动效、实拍合成、想做更多效果 → **PR + AE**（工程规范和 AE 技法见 `14-AE合成技法.md`）。下面的轨道结构、操作顺序、字幕和响度规范两边通用。

---

## 一、剪辑工程规范

### 轨道结构（从上到下）

```
V3  封面/贴纸/包装
V2  字幕
V1  主体片段（seg01 → seg02 → …）
A2  BGM
A1  音效 / 环境音
A0  原片声音（模型生成的人声 + 音效）← 不要删，只调节音量
```

### 操作顺序

1. 素材按分镜顺序铺到 V1，**开头加 0.5 秒黑屏**（短剧开场的呼吸感）
2. **接缝处理**：段与段之间如果是"动作接动作"，用 2–3 帧的重叠对齐；否则硬切
3. **声先入**：把下一段的声音提前 0.5 秒进入（最便宜的"高级感"）
4. 音效库补「人声以外的声音」：环境音、动作音、转场音
5. BGM 单独一条轨，按 `04-声音与音画同步.md` 的情绪走向表铺；台词段让位给人声（BGM 比人声低 12–18 dB 左右）
6. 字幕：用 `scripts/make_srt.py` 从分镜表直接导出 SRT 再导入（人名、多音字不会错）；或智能识别后**手动改错**
7. **响度统一**：成片约 **−14 LUFS**，真峰值不超过 **−1 dBTP**（音乐向 MV 见 `13-拼贴风MV.md`）。PR 在导出设置里开「响度标准化」，剪映用音量统一后再听一遍
8. 导出：1080×1920；**帧率跟素材走，全片统一**（混帧率拼接会卡顿）；码率拉到平台推荐值

### 字幕规范

| 项 | 建议 |
|---|---|
| 字号 | 竖屏安全区内，单行不超过 12 字 |
| 位置 | 底部上方约 15% 处，避开平台 UI 遮挡区 |
| 速度 | 与语音同步，单条停留 ≥ 0.8 秒 |
| 样式 | 全片统一，一次设定好复用 |
| 断句 | 手动断，不要机器平均分 |

## 二、封面 / 标题 / 简介 / 话题

### 封面

- **必须有脸**（有脸的封面点击率高）
- 一张脸 + 一个情绪 + 一句话（≤8 字）
- 用 **Seedream 5.0 Pro** 出（中文标题字渲染强）
- 竖屏 3:4 或 9:16，注意平台裁切

### 标题模板（挑一个套）

| 类型 | 模板 | 例子 |
|---|---|---|
| 冲突前置 | `{她被X的瞬间，全场安静了}` | |
| 身份反转 | `{所有人都以为她是X，直到Y}` | |
| 疑问钩子 | `{如果重来一次，你还会X吗？}` | |
| 数字/进度 | `{第3集｜我终于X了}` | |
| 台词原句 | 直接用最狠的那句台词 | |

**标题里可以放剧名 + 集数**，便于建立追更习惯。

### 简介

```
<一句话剧情钩子>
本集看点：<2–3 个>
#<题材标签> #漫剧 #AI短剧 #<情绪标签>
```

### 话题标签

- 题材词：#复仇 #重生 #逆袭 #玄幻
- 品类词：#漫剧 #AI短剧 #AI动画
- 情绪词：#爽文 #打脸 #虐心
- 平台活动词：跟当期官方话题

## 三、★ AI 生成内容合规标识

平台明确要求 AI 生成内容做显式标识。三条都做：

1. **发布时勾选平台的"AI 生成"声明**（抖音/红果/快手/B站都有）
2. **简介里写明**："本片由 AI 生成" / "画面与配音由 AI 生成"
3. **片尾加一帧标识**（可选但推荐）

**不要试图隐藏。** 被平台判定未标识的处罚远大于标识带来的流量损失。

**依据**：《人工智能生成合成内容标识办法》2025 年 9 月 1 日起施行，要求显式标识（用户看得到的提示）和隐式标识（文件元数据里的信息）。实操上：用正规平台生成；**不要刻意清除生成工具写进文件的元数据**；剪辑重新导出后元数据可能不再保留，所以发布时的平台声明和简介说明一定要做。具体要求以平台当时公告为准。

## 四、发布节奏

| 阶段 | 节奏 |
|---|---|
| 试播集 | 单发，观察 48 小时数据 |
| 前 3 集 | **连更 3 天**（把完播和追更意愿一次测出来） |
| 稳定期 | 日更或隔日更，固定时间（晚 8–10 点） |
| 长线 | 保持 20 集以上的库存缓冲，别断更 |

**一集时长按平台调**：抖音偏 60–90 秒；红果可到 2–3 分钟。

## 五、数据回收 → 剧本迭代闭环

**这一层是很多人漏掉的：发完不看数据 = 白做。**

### 看哪三个数

| 指标 | 健康线 | 不达标说明什么 |
|---|---|---|
| **3 秒完播率** | > 70% | 开场钩子不行 → 改前 3 秒 |
| **整体完播率** | > 35% | 中段节奏拖 → 砍段、加快切镜 |
| **追更率 / 关注转化** | 看趋势 | 结尾钩子不行 → 换钩子类型 |

### 反推修改表

| 数据症状 | 大概率原因 | 下一集怎么改 |
|---|---|---|
| 3 秒跳出高 | 开场空镜 / 信息量低 | 换成"结果前置"或"台词入画" |
| 中段掉 | 段落超过 12 秒 / 连续同景别 | 缩短段长，插入特写和运动镜头 |
| 结尾掉 | 钩子太弱或提前泄底 | 换钩子类型，在揭穿前 0.5 秒切断 |
| 完播好但不涨粉 | 缺"必须追下一集"的理由 | 加一条贯穿全剧的悬念主线 |
| 互动低 | 没有争论点 | 加一个立场对立的选择 |

**每 3 集做一次复盘**，把结论写回 `01_剧本/剧集大纲.md`。
