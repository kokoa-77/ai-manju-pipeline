# ⑤ 提示词工程（四段式 · 官方结构）

**这一层最费人力，也最决定成片率。** 同一条素材，提示词写得好坏，出片率能差 3 倍。

---

## 一、四段式结构（顺序固定，不许调）

```
【第一段 · 素材指代】
@图片1用于林晚的五官、发型和酒红丝绒长裙，不采用图片背景。
@图片2用于婚礼彩排厅的空间布局、材质和光线，不采用图中人物。
@音频1作为林晚的配音音色参考。

【第二段 · 一句话概述】
林晚在婚礼彩排晚宴上被苏黎当众递酒羞辱，她接过酒杯又反手泼回。画面呈现冷调电影质感，
镜头采用缓慢推近配合手持微晃。

【第三段 · 逐段时间戳】（2.5 的强项，务必写）
0s-3s：中景，林晚站在长桌一侧，指尖抵着酒杯底座。<宴会厅人声>
3s-5s：镜头缓慢推近至近景。苏黎递过酒杯，嘴角上挑。苏黎说{姐姐，敬你一杯}。语气甜，尾音上扬。
5s-7s：停顿。林晚垂眼看酒杯，没有接。 <酒杯轻碰声>
7s-10s：林晚抬眼，反手把酒泼出。镜头跟着手部动作快速横摇。

【第四段 · 结尾守则】
角色外观全程保持一致；不要字幕；不要背景音乐；保持 9:16 竖屏。
```

> **`@图片N` 是这一条的上传槽位**：按上传顺序从 1 编号（图片 → 视频 → 音频），不是编号表编号。用 `scripts/build_prompts.py` 生成时会自动换算并给出上传清单，规则见 `02-资产与角色圣经.md` 第五节。

## 二、符号系统（必须背下来）

| 内容 | 符号 | 示例 |
|---|---|---|
| 台词 | `{}` | `{你好，欢迎回来}` |
| 音效 | `<>` | `<远处传来钟声>` |
| 音乐 | `()` | `(背景播放舒缓的钢琴乐)` |
| 字幕 | `【】` | `【第一章：启程】` |

> ⚠️ **实际生产建议：不要用 `( )` 写音乐、不要用 `【】` 写字幕。** 交给剪辑软件做，模型会把你写的东西直接画进画面。`( )` 和 `【】` 只在你确实想让它出现在画面里时才用。

---

## 三、时间戳写法（2.5 的核心能力）

### 三种写法，按精度递减

| 写法 | 例子 | 何时用 |
|---|---|---|
| **秒级区间**（推荐） | `0s-3s：` `3s-5s：` | 有台词、有音效、动作需要卡点 |
| **镜次** | `镜头1：` `镜头2：` | 纯画面、无台词、节奏宽松 |
| **混合** | `0s-4s 镜头1：…` | 长段、需要双重定位 |

### 三条硬规则

1. **区间绝不能重叠。** 同时写 `3s-6s` 和 `5s-8s` 两句台词 = 音轨叠加，口型全乱。
2. **单句时长 = 实际发音 + 0.5 秒缓冲。** 中文 5 字/秒，`{你和姐姐的事，我早就知道}` 是 11 字 ≈ 2.2 秒 → 给 `2.5s-3s` 的余量。
3. **一条生成里所有台词必须同一语言。** 中英混写出错。

### 超过 30 秒怎么办

单次生成上限 30 秒（官方口径）。更长的用两条路：

- **时序延长**：接上一条的尾巴继续生成，见 `05-生成抽卡与验收.md`
- **拆段拼接**：分镜表拆成 seg01、seg02，每段独立生成后在剪映接。**推荐这条**，废片率低

**跨段的时间轴不连续编号** —— 每段从 `0s` 重新开始，段号才是全局标识。

## 四、否定约束标准清单（模型默认会加东西）

模型默认会给你加**字幕**和**BGM**。要什么不要什么，必须显式写。

| 想要的效果 | 写什么 |
|---|---|
| 无字幕 | `不要字幕` |
| 无背景音乐 | `不要背景音乐` |
| 完全静音（只留音效） | `不要任何声音`（慎用，会连音效一起去掉） |
| 无画面文字 | `不要画面内文字、不要水印、不要logo` |
| 无多余人物 | `画面中只有这<2>个人，不要出现其他人脸` |
| 保持画幅 | `保持 9:16 竖屏` |
| 保持角色一致 | `角色外观全程保持一致` |

**标准结尾守则（直接抄）**：
```
角色外观全程保持一致；不要字幕；不要背景音乐；不要画面内文字；
保持 9:16 竖屏；不要出现提示词以外的人物。
```

## 五、情绪要外化，不要写形容词

**规则：不写"很悲伤"，写身体细节。**

| ❌ 抽象 | ✅ 外化 |
|---|---|
| 她很悲伤 | 低头、肩膀轻颤、攥紧衣角 |
| 他很愤怒 | 下颌咬紧、指节发白、呼吸变重 |
| 她很惊讶 | 瞳孔微缩、手中杯子倾斜、后退半步 |
| 他很有压迫感 | 站着不动、视线压过去、影子盖住对方 |
| 她很得意 | 嘴角单侧上挑、眼神扫过对方头顶 |
| 她强忍情绪 | 眨眼变慢、喉结动了一下、指尖抵住桌沿 |

### 动作写法四则（官方倾向）

1. **肢体细化 + 程度量化** —— "手抖" → "手指颤抖，幅度约一寸"
2. **优先低缓、连续的小动作** —— 官方建议**避开狂奔、大跳、翻滚**；能量交给剪辑节奏和运镜
3. **写动作衔接** —— "抬手 → 停顿 → 落下"比 "挥手" 好
4. **情绪具象外化** —— 见上表

## 六、光影段 + 色调三层结构

**每条 prompt 留一个独立的光影句。** 三要素：

```
光源方向 + 质感 + 对比度
```

示例：`光源来自右上方水晶吊灯，暖金色硬光在左颊留下锐利阴影，暗部压到底，高光克制。`

**色调三层结构**（从系列圣经抄，全片统一）：

```
<主色调>为主色调，<次色调>为次色调，<点缀色>作为点缀。
```

示例：`象牙白与香槟金为主色调，酒红丝绒为次色调，烛火橙黄作为高光点缀。`

## 七、素材冲突处理

参考图之间打架是常见问题（比如角色图的冷白光 vs 场景图的暖黄光）。处理顺序：

1. **分开职责**：角色图只用于"五官/发型/服装"，明确写 `不采用图片背景`
2. **场景图只用于"空间布局、材质、光线"**，明确写 `不采用图中人物`
3. **在光影句里强制统一**：`画面统一采用场景图的暖金光作为主光，角色图的冷白光仅用于肤色参考，不用于画面光效`
4. 仍然打架 → **换掉那张冲突的素材**，别在提示词里硬压

---

## 八、长度控制

- 官方参考区间：**500–1500 字**
- **素材本身够准时，只做指代，别复述画面**（素材里有的东西再写一遍是浪费长度）
- 超 1500 字：优先砍"形容词"和"重复约束"，不要砍时间戳和台词

## 九、完整对照示例

### ❌ 差的写法

```
一个女生在宴会上很生气，然后她泼了酒，气氛很紧张，电影感。
```
问题：没有主体指代 / 没有时间戳 / 没有台词音效 / "很生气""很紧张"是抽象词 / 没有结尾守则。

### ✅ 好的写法

```
【素材指代】
@图片1用于林晚的五官、发型和酒红丝绒长裙，不采用图片背景。
@图片2用于婚礼彩排厅的空间布局、材质和光线，不采用图中人物。
@音频1作为林晚的配音音色参考。

【概述】
林晚在婚礼彩排晚宴上当众被苏黎递酒羞辱，她反手将酒泼回。画面为冷调电影质感，
镜头从固定中景缓慢推近，最后跟随手部动作横摇。

【时间戳】
0s-3s：中景，平视。林晚站在长桌一侧，指尖抵着酒杯底座，视线落在桌面上。
       光源来自右上方水晶吊灯，暖金硬光在她左颊留下锐利阴影。<宴会厅人声>
3s-5s：镜头缓慢推近至近景。苏黎从画面右侧入画递出酒杯，嘴角单侧上挑。
       苏黎说{姐姐，敬你一杯}。语气甜，尾音上扬。
5s-7.5s：停顿。林晚垂眼看酒杯，没有伸手接。眨眼变慢，喉结动了一下。<酒杯轻碰声>
7.5s-10s：林晚抬眼，反手把酒泼出。镜头跟着手部动作快速横摇至苏黎侧脸。
       <玻璃碎裂声> 苏黎脸上笑容凝固，瞳孔微缩，后退半步。

【守则】
角色外观全程保持一致；不要字幕；不要背景音乐；不要画面内文字；
保持 9:16 竖屏；画面中只有林晚和苏黎两人。
```

## 十、多语言 / 出海（白捡的一条路）

Seedance 2.5 **原生支持 10+ 语言**，且音色特征**与语言无关**（中文音色可跨语种复刻）。

非中文台词加固写法：

```
台词语言：美式英语。女孩用自然、口语化的美式英语说：{I knew it all along.}
```

**注意**：同一条生成里只能一种语言。出海版要另起一条，不能在同一条里混。

## 十二、提示词自检清单

- [ ] 第一段有素材指代，且每个 `@图片N` 都能在编号表查到
- [ ] 每个"不采用"都写了
- [ ] 第二段有一句话概述（主体 + 事件 + 风格 + 运镜）
- [ ] 第三段所有区间**无重叠**
- [ ] 每句台词的单句时长够（字数 ÷ 5 + 0.5 秒）
- [ ] 台词标了说话人**姓名**，不是"角色1"
- [ ] 每条生成内只有一种语言
- [ ] 有独立的光影句，且色调三层写全
- [ ] 结尾守则写全（含否定约束）
- [ ] 总长在 500–1500 字之间
