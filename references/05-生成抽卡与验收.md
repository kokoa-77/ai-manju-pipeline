# ⑥⑦ 生成、抽卡与验收

**这一层用户自己跑（我无法调用即梦/豆包/火山方舟 API）。** 我的职责是把 SOP、预算、判定标准给到位，让用户少浪费抽卡次数。

---

## 一、入口与参数

| 项 | 值 |
|---|---|
| 入口 | 即梦网页端（视频生成 → 选 Seedance 2.5）/ 豆包专业版 / 火山方舟 API |
| 时长 | 4–30 秒 |
| 分辨率 | 720P 起（可到 1080P / 4K） |
| 画幅 | 9:16 竖屏（可 0.4–2.5 任意比例） |
| 声音 | **开启**（不开就没有原生对白） |
| 上传顺序 | 图片 → 视频 → **音色参考（永远最后）**，按提示词包每条的「上传清单」 |

## 二、A 派 vs B 派

| | A 直出派 | **B 稳派（默认推荐）** |
|---|---|---|
| 做法 | 分镜板 ≤4 格 → 单条多段时间戳，一条 30 秒搞定 | 5–8 段，每段 6–10 秒（上限 12）单条生成、单条审核 |
| 适合 | 对白密集、单一场景的连续戏 | 动作、多人、复杂调度 |
| 风险 | 抽一次废一次，30 秒的成本是 10 秒的 3 倍 | 剪辑点多，但废片率低 |

**一集里可以混用**：单一场景的对话戏用 A 派合并，动作/多人戏用 B 派拆段。分镜表里标清楚哪几段合并成一条。

## 三、生成顺序 SOP

```
第 1 轮：只生成 seg01（开场段）
        ↓ 确认脸、画风、音色都对了
第 2 轮：生成所有"有台词"的段（这些最贵、最容易崩）
        ↓
第 3 轮：生成纯动作/过场段（可以用 Seedance 2.0 省钱）
        ↓
第 4 轮：全部生成完 → 跨段验收 → 补抽 / 定点修
```

**不要一次把 6 段全丢进去跑。** 第 1 段就是校准基准 —— 它错了，后面 5 段全错。

**省钱规则**：过场 / 空镜 / 无人段用 **Seedance 2.0**（¥46/百万 token），重头戏用 **2.5**（¥70/百万 token，贵 52%）。

## 四、抽卡预算表

一段 6–12 秒的镜头，**平均抽 3–5 次**能过。重要镜头（开场、反杀、结尾钩子）预留 **8–10 次**。

> 这些数字是起步假设。每次生成都记进 `生成日志.csv`（模板 `assets/生成日志模板.csv`），做满 3 集后跑 `scripts/log_summary.py`，换成你自己的真实抽卡率、工时和单集成本。

| 段类型 | 预计次数 | 备注 |
|---|---|---|
| 单人纯动作、无台词 | 2–3 | 最稳 |
| 单人带台词 | 3–5 | 口型是变量 |
| 双人对话 | 4–6 | 音色绑定 + 站位 |
| 多人同框（3+） | 6–10 | 最容易崩，能拆就拆 |
| 复杂运镜 | 5–8 | 考虑加白模参考 |
| 开场 / 结尾钩子 | 8–10 | 值得多花 |

> ⚠️ **单位成本按你实际账单校准。** Seedance 2.5 官方标价 ¥70 / 百万 token（2.0 是 ¥46）。一集 6 段 × 平均 4 次 = 24 次生成，先跑一集把真实单价测出来，再乘算。

**降低抽卡次数的四件事**（按性价比排序）：
1. 提示词的时间戳写细（最常见的崩因）
2. 资产做干净（三视图白底、五官清楚）
3. 素材数量控制在稳定区（图片 1–8 个主体）
4. 动作避开狂奔/大跳/翻滚

## 五、废片判定（什么该修，什么该重抽）

**总原则：一处问题 → 定点修；两处以上 → 重抽。**

| 症状 | 判定 | 处理 |
|---|---|---|
| 脸不像主角 | 🔴 严重 | **重抽**，检查素材是不是被背景污染 |
| 换脸了（中途变形） | 🔴 严重 | 重抽，缩短段长 |
| 口型对不上 | 🟡 中度 | 先改时间戳重抽；残余 0.2s 内用剪映拖 |
| 动作崩坏 | 🔴 严重 | 重抽，把动作写细、降幅度 |
| 服装款式错 | 🟢 轻度 | 定点编辑，或补一张服装参考图 |
| 画面多了个人 | 🟢 轻度 | 定点编辑擦除 |
| 光线方向不对 | 🟢 轻度 | 定点编辑换光 |
| 构图不好 | 🟢 轻度 | 定点编辑调运镜（见下） |
| 画面里出现字幕 | 🟢 轻度 | 定点编辑去掉，或加强否定约束重抽 |
| 整段节奏拖 | 🔴 严重 | 重抽，缩短段长 |

## 六、定点修改（不重生成全片）

用于**只改一处、其余保持**的场景：

```
编辑 @视频1，保持人物、动作及画风不变，仅调整运镜：
0-4 秒，微型 FPV 贴地穿行，镜头高度约 15 厘米，匀速前进。
```

```
编辑 @视频1，保持人物、动作及画风不变，删除画面右侧出现的第三个人物，
背景保持原样，不要改变光线。
```

**Seedance 2.5 的编辑能力**（该用就用）：
- 局部定点编辑（框选区域 / 箭头 / 坐标指定改哪一块）
- 视角编辑、运镜编辑
- 绿幕编辑（换背景）
- 视频无缝转场
- 白模渲染（复杂运镜时用白模当运镜参考）
- **宫格分镜**（分镜板直接转视频，适合 A 派）

## 七、时序延长（接上一条的尾巴）

```
延长视频，衔接 @视频1 画面内容和主体继续生成一个 30 秒的视频，
保持人物主体、场景、画面风格、声音音效一致。<后续剧情>
```

**接缝处理**：
- 延长处的第一帧必须和上一条的最后一帧**动作连续**（写进提示词）
- 接缝处的 BGM 和音效在剪映里做淡入淡出
- 延长后**必须重新做一次音画对齐校验**（延长段最容易偏）

## 八、★ 跨段验收清单（全部生成完后逐项打钩）

生成完一集的所有段之后，**不要直接进剪辑**。先做这套验收：

### 视觉一致性

- [ ] 把每段里每个角色的脸**截帧拼成一张对比图**，一眼看是否同一个人
- [ ] 服装颜色、款式、配饰位置全段一致
- [ ] 发型（尤其背面视角）一致
- [ ] 身形比例、身高差一致
- [ ] 肤色在不同光线下没有跑偏

### 连续性

- [ ] 光线方向在段间不变（除非剧情要求）
- [ ] 道具位置接得上（换手、换桌、消失）
- [ ] 人物站位和相对位置接得上
- [ ] 一天中的时间一致
- [ ] 动作接动作的转场点对得上

### 声音

- [ ] 每段音色都是指定角色（不是系统默认音）
- [ ] 多角色音色没串
- [ ] 台词语言单一
- [ ] 1.2 倍速全片播过，音画偏差都可接受

### 内容

- [ ] 每段都没有字幕和 BGM（除非刻意要）
- [ ] 台词原文和剧本一致（模型可能改字）
- [ ] 结尾钩子在最后 3 秒内

**任何一项不过 → 回到对应段处理，不要带病进剪辑。**
