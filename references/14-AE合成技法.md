# 14 · PR + AE 工程规范与合成技法

> **一句话定位**：剪映做不了的，在这里做。PR 负责剪，AE 负责合成和特效。
> 同人 MV 必走这条；商业漫剧想做更多包装时也能用（竖屏序列、字幕模板、系列 LUT 都能直接带过去）。

---

## 一、分工

| 软件 | 干什么 |
|---|---|
| **PR** | 按歌曲卡点粗剪、歌词 / 台词时间轴、调色（Lumetri）、响度、导出 |
| **AE** | 实拍跟踪合成、拼贴动效、手写字动画、2.5D 镜头、名卡、职员表 |
| Audition（可选） | 音频降噪、修复 |
| 达芬奇（备选） | 不想付 Adobe 订阅时的免费替代：剪辑 + Fusion 合成 + 调色 |
| 剪映（可选） | 只在手机上快速改抖音版、套平台热门模板时用 |

---

## 二、工程规范

| 项 | 规范 |
|---|---|
| 序列 | 横版 1920×1080 25fps（B站）；竖版 1080×1920 25fps（漫剧 / 切片） |
| 帧率 | **全片统一**。24fps 的 AI 素材进 AE 后「解释素材」设成 25；混帧率拼接会卡顿 |
| 宽银幕段落 | 用调整图层加黑边，不改序列尺寸 |
| 素材箱 | 和项目目录一一对应：`02_资产 / 04_视频片段 / 05_音乐声音` |
| PR ↔ AE | 动态链接，不来回导出中间文件 |
| 一拍二 | Q 版和作画镜头给角色层加「色调分离时间」（Posterize Time）设 12 或 12.5；镜头运动层可以保持全帧，两种都试 |
| 字幕 | 做成 MOGRT 模板（字体、描边、位置、淡入淡出固定），全系列共用；时间轴用 `scripts/make_srt.py` 从分镜表导出 SRT |
| 字体 | 只用确认可商用的字体，或你自己的手写字 |
| 调色 | 一个系列 LUT 套在调整图层上 |
| 响度 | 导出设置里打开「响度标准化」：剧情 −14 LUFS、音乐向 MV −9 到 −12 LUFS，真峰值 ≤ −1 dBTP |
| 导出预设 | B站横版、抖音竖版、小红书竖版各存一个，按平台推荐码率 |
| 归档 | 每条定稿后 AE「整理工程」打包，和素材一起备份 |

**显卡**：AI 跑图、超分和 AE 渲染都吃显卡，不要同时开。

## 三、AE 必练技法

| 技法 | 用在（13 的镜头类型） | 关键工具 |
|---|---|---|
| **实拍跟踪合成** | 1 | 3D 摄像机跟踪器 → 在跟踪点上建空对象 → 贴 Q 版 PNG；平面（桌面、墙面）用 Mocha AE（AE 自带） |
| **贴纸质感** | 1、3、8 | 白色外描边、投影、轻微随机抖动（`wiggle` 表达式）、出场弹一下（overshoot 表达式） |
| **手写书写动画** | 4、12 | 手写字转矢量 → 「描边」效果做书写路径动画，或蒙版逐笔显示 |
| **拼贴动效** | 3、5 | 纸张「毛边」效果、胶带遮罩撕开、图层按拍点逐个弹入；整体叠一层纸张纹理 |
| **2.5D 视差** | 6 | 场景拆前 / 中 / 远三层 → 3D 图层 + 摄像机慢推；加景深模糊 |
| **Q 版小动作** | 1、8 | 操控点工具：呼吸起伏、挥手、跳一下；眨眼用两张差分切换 |
| **宫格 / 画中画** | 9、10 | 预合成做模板，时长按拍点复制 |
| **涂鸦线条** | 3、4 | 你画的线条序列帧，或形状层 + 修剪路径 + 湍流置换做抖动 |

插件按需加：Saber（免费光效）、Deep Glow（光效）。别一开始就装一堆。

### 开工前的 4 个练习（每个 10–20 秒，不发布）

1. 拍一段桌面推镜 → 跟踪 → 贴一个 Q 版小人 → 加白边投影
2. 手写系列标题 → 做书写动画
3. 5 层拼贴素材按节拍逐个弹入
4. 一张场景图拆 3 层 → 2.5D 推镜

## 四、AE 分层动态漫（最省抽卡的做法）

```
角色层：Qwen-Image 2.1 / Seedream 出透明背景 PNG（或 BiRefNet 抠图）
        表情差分 + 口型 2–3 张（张嘴 / 半张 / 闭嘴）
背景层：同场景一张空镜，拆成前景 / 中景 / 远景
特效层：光斑、花瓣、雨、粒子（AE 或 Saber）
        ↓
AE 3D 摄像机：推拉、平移、视差 → 2.5D 镜头运动
角色小动作：呼吸、眨眼、头发飘动（操控点 / 变形）
        ↓
PR 卡点 + 音乐
```

**好处**：

- 背景永远一致，角色不会崩脸，因为就是同一张图
- 几乎不用视频模型抽卡，成本最低
- 人工比重最高，二次元圈接受度最好
- 和 AI 视频镜头混剪：情绪高潮用 AI 视频，过渡和对话用分层，节奏更像番剧

## 五、AI 视频素材进 AE 前的处理

| 步骤 | 做法 |
|---|---|
| 超分 | MiniMax H3 本地版约 768p → Real-CUGAN / Real-ESRGAN 动漫版拉到 1080p（见 `08-本地免费出图.md`） |
| 帧率 | 解释素材统一到工程帧率 |
| 调色 | 先套系列 LUT，再微调；AI 素材每条的光影都不一样，这一步不能省 |
| 质感 | 角色层一拍二；加一层很淡的纸张或胶片颗粒，让 AI 画面和手绘素材融在一起 |
| 抠像 | 需要把 AI 生成的角色放到别的背景上时，用 SAM 2 / MatAnyone |
