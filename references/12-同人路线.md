# 12 · 同人路线（二次元同人视频）

> **一句话定位**：同人期不是为了赚钱，是借别人 IP 的热度，低成本把你自己的生产线跑熟。
> 同人期结束时，流程、数据、风格、音乐、粉丝和作品集都能带进商业期；带不走的只有 IP 角色本身和 IP 带来的流量。

**最大的认知陷阱**：同人视频数据好，很可能是 IP 的功劳。所以中途一定要插一段原创测试，看粉丝是跟你，还是跟 IP（见第六节）。

---

## 一、四条原则

1. **每个阶段只练一个新能力。** 先练画面一致性，再练台词口型，再练连载。
2. **只做一个 IP、一到两个角色，直到毕业。** 角色越少，资产复用越多，进步越快。
3. **资产所有权从第一天分清。** IP 角色的资产只用于同人；你自己画的画风、做的音乐、写的原创角色单独归档。
4. **AI 是工具，你是作者。** 二次元圈对 AI 敏感，把人工的部分（手绘、作曲、剪辑）亮出来，而不是藏起来。

---

## 二、选 IP

### 2.1 IP 类型

| 类型 | 适合做什么 | 注意 |
|---|---|---|
| 动漫（新番） | 播出期热度高，适合角色日常、名场面致敬 | 热度来得快去得快，开播后 2–4 周内出片最好 |
| 动漫（经典 / 完结） | 情怀向、回忆向 MV，长尾播放 | 同类作品多，靠风格差异化 |
| 游戏 | 有活动和版本节点，粉丝活跃 | 查厂商二创规范，部分厂商写得很细 |
| 漫画 / 轻小说 / 网文 | 还没动画化，「帮它动起来」很吸引原作粉 | 外形以原作插图为准 |
| Vtuber / 虚拟歌手 | 粉丝黏性强，切片和 MV 需求大 | 多数事务所有二创规约，不少对 AI 作品有明确限制，**先读规约** |

### 2.2 打分表（每项 1–5 分，选总分最高的）

| 维度 | 看什么 | 为什么 |
|---|---|---|
| 熟悉度 | 你是不是真爱粉，能不能闭眼说出角色口癖 | 熟悉度低 = OOC，同人观众最不能忍 |
| 热度 | 新番、新一季、新活动、新版本 | 有搜索量，新号也能被看到 |
| 官方二创态度 | 官网 / 官方账号有没有二创指引，有没有投诉过二创 | 决定能做到哪一步 |
| 圈子对 AI 的态度 | 搜「IP 名 + AI」，看评论区 | 有的圈子很抵触，新号进去会被冲 |
| 造型难度 | 服装、发饰、武器复不复杂；Q 版化好不好画 | 复杂造型 AI 每帧都会画错 |
| 风格契合度 | 世界观适不适合你要做的风格 | 例：拼贴风适合「日常 / 旅行 / 回忆」 |

**建议**：第一个 IP 选「你很熟 + 造型简单 + 官方友好 + 圈子不太排斥 AI」的。热度排在后面。

---

## 三、设定考据与 OOC 检查

每个角色一份设定考据（模板 `assets/设定考据模板.md`）：外形锁死、Q 版锁定、口癖、称呼、绝对不会说的话、关系、名场面、粉丝雷点。

**OOC 检查清单**（剧本定稿前逐条过）：

- [ ] 自称、称呼别人的方式和原作一致
- [ ] 没有让角色说出「绝对不会说的话」
- [ ] 情绪表达方式符合人设（会忍着哭的角色别让 TA 嚎啕）
- [ ] 关系没写反、CP 没拆逆（按目标观众的口味）
- [ ] 世界观设定没写错（能力、时间线、地名）
- [ ] 让一个同样熟悉原作的朋友看一遍台词

## 四、钩子换成同人版

商业漫剧的 3+3+3 和黄金 6 秒照样能用，但钩子要换：

| 商业漫剧 | 同人 |
|---|---|
| 身份反转、打脸 | 名场面复刻 / IF 线反转 |
| 结尾悬念切断 | 粉丝梗收尾、CP 糖点 |
| 黄金前 6 秒冲突 | 前 3 秒让粉丝认出「是 TA」+ 一个梗 |

分镜表可以加一列「致敬 / 梗」，标清楚每个镜头在致敬什么。

## 五、阶段路线

| 阶段 | 时间（参考） | 做什么 | 毕业标准 |
|---|---|---|---|
| **0 准备** | 第 1–3 周 | 选 IP、风格圣经、角色资产、AE 基础练习 | 角色定妆 + Q 版差分 + 风格帧定稿 |
| **1 镜头模块短片** | 第 4–11 周 | 4 条 30–90 秒无台词短片，每条主攻一组镜头（见 `13-拼贴风MV.md`） | 9 种以上镜头类型做过；知道每种的工时 |
| **2 完整 MV 代表作** | 第 12–19 周 | 一首完整原创曲（3–4 分钟） | 代表作 + 副歌切片 + 幕后视频发布 |
| **3 小剧场 + 原创孵化** | 第 20–32 周 | 有台词的同人小剧场（接本仓库主流程）+ 原创角色 MV | 音色绑定稳定；原创作品有数据对比 |
| **4 转商业** | 第 8 个月起 | MV/PV 商单 + 原创 IP + 漫剧 | 见第八节 |

时间按每周 15–25 小时估。投入少就拉长，**顺序不要跳**。

## 六、原创孵化（阶段 3）

- **角色**：用你的画风设计 1–2 个原创角色，可以和同人角色同一种气质，但设定、名字、外形完全是你的
- **音乐**：给原创角色写主题曲，作为系列级资产
- **模型链路换成可商用的**（见 `07-翻车点与模型选型.md` 许可证表），原创资产才能直接带进商业期
- **看数据**：原创作品的平均观看进度、互动率、涨粉，对比同期同人作品
  - 接近 → 粉丝认的是你，可以准备转商业
  - 差很多 → 继续积累、调整原创方向，**不要因此放弃原创**，IP 红利本来就有落差

**第二条内容线：幕后 / 教程。** 每 3–4 条作品出一条「我怎么用手绘 + AI + 作曲做这条视频」。把 AI 的敏感变成内容，也是以后接商单最好的能力证明。

## 七、合规与圈子礼仪

| 项目 | 做法 |
|---|---|
| AI 标识 | 平台勾选 + 简介写明；不清除生成工具的元数据（见 `06-后期发布与数据.md` 第三节） |
| 同人版权 | 同人期**不开 IP 相关的商业变现**：不卖周边、不接相关广告；平台激励收益算不算商用有争议，不确定就不开；官方要求下架立刻配合 |
| 官方素材 | 不用官方 PV 画面、官方立绘当主要素材，角色由你重新画 |
| 二创规范 | 开工前查 IP 官方的二创指引，按指引来 |
| 声音 | 不克隆原作声优，不克隆任何真人的声音（除非本人书面授权） |
| 原作音乐 | 不用原作 OST、不用流行歌，用自己的音乐 |
| 未成年形象 | 二次元角色外形普遍偏小，**绝不做擦边、暴露、性暗示内容** |
| 字体 | 封面和字幕只用确认可商用的字体，或你自己的手写字 |

**圈子礼仪**（不违法，但会被冲）：

- 主动标 AI，不要等别人扒出来
- 不打纯手绘标签，不参加只收手绘的活动
- 不模仿在世画师的画风，提示词里不写画师名字
- 不用别人的同人图训 LoRA；不公开分享你的角色 LoRA
- 被质疑时不吵架，放制作过程：手绘设定稿、作曲工程截图

**平台审核拦截**：AI 平台对打斗流血、亲密接触、像未成年的形象会拦截或悄悄降质。用替代写法（动作前一刻切反应镜头、用表情和喘息代替血、牵手对视代替亲密戏）；被拦后先改写再提交，**不要原样反复提交**。

## 八、转商业检查清单

**能力**
- [ ] 一支完整 MV 从作曲到发布独立做完
- [ ] 跑过 `scripts/log_summary.py`，知道每种镜头的平均工时和成本，能报价
- [ ] 台词、音色、跨集一致性有稳定解法

**资产**
- [ ] 至少 1 个原创 IP：角色（正常 + Q 版）、风格圣经、主题曲
- [ ] 原创资产库里没有任何 IP 方的东西（包括用官方图训的 LoRA）
- [ ] 成品链路的每个模型都核对过商用许可

**市场**
- [ ] 作品集：代表作 MV + 2–3 支短片 + 幕后视频
- [ ] 原创作品测过水，有数据
- [ ] 查过目标平台入驻要求、微短剧备案要求

**商业方向（按见钱速度排）**：

| 方向 | 为什么 |
|---|---|
| 1. MV / PV 商单 | 游戏、虚拟主播、独立歌手、品牌都买这种内容；「作曲 + 美术 + AE」一个人包圆很少见 |
| 2. 原创 IP + 原创音乐 MV | 和同人期账号无缝衔接 |
| 3. 原创漫剧 | 长期方向，走本仓库 01–11 的完整商业流程 |
