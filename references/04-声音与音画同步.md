# ④ 声音层与音画同步

**Seedance 2.5 原生音画同步**（语音 + 表演动作 + 可见口型联合生成），所以这一层的目标是：**让模型的"原生"真的生效**。做错一步，全片退化成系统默认音。

---

## 一、音色样本规范

| 项 | 要求 |
|---|---|
| 时长 | **5–15 秒**（太短抓不住特征，太长没必要） |
| 格式 | WAV / MP3 |
| 采样率 | **44100Hz**（建议） |
| 内容 | **任意语言、任意内容都行** —— 模型提取的是音色特征，不是说话内容 |
| 必须无 | 杂音、背景音乐、混响、其他人声 |
| 音质 | 越干净，复刻越准 |

**关键事实**：音色特征**与语言无关**。录一段中文 → 可以让这个音色说英文。这是做出海版的基础。

### 怎么拿到样本

| 方式 | 说明 |
|---|---|
| 豆包语音 / 剪映朗读 | 生成一段干净朗读，导出音频 |
| 真人自录 | 手机录也行，但**必须无环境噪音** |
| Seed Audio 1.0 | 直接合成音色样本 |

---

## 二、★ 上传顺序（硬规则，错了全废）

```
① 角色正面图  →  ② 白模  →  ③ 运镜参考  →  ④ 音色参考（第 4 位）
```

**顺序颠倒的后果**：音色会被绑到默认白模上 → **全片变系统默认音**。

### 多角色绑定（必须逐个做）

1. 每个角色单独上传自己的音色参考
2. 每个音色**逐个勾选「仅当前角色可用」**
3. 不勾 → 音色串用（A 的声音跑到 B 嘴里）

**提示词里每句台词都要标注角色姓名**，不许写"角色1""角色2"——模型对不上人。

---

## 三、台词语言规则

| 规则 | 说明 |
|---|---|
| 一条生成内**只能一种语言** | 一句中文一句英文混写 → 模型出错 |
| 非中文要加固 | `台词语言：美式英语。女孩用自然口语化的美式英语说：{...}` |
| 出海版另起一条 | 不能在同一条里做双语 |

---

## 四、音画对齐校验流程

生成完之后，**必须做这套校验**，不能直接进剪辑：

1. **逐段播放**，看口型是否对得上台词
2. **按 1.2 倍速全片播放一遍** —— 倍速下细微偏差会明显暴露
3. 发现偏差 → 框选异常片段 → 用「音画同步调整」→ 音轨偏移滑块按 **0.1s 步长**微调
4. **0.2 秒以内的残余偏差** → 不用在模型里调，导出后在剪映/PR 里拖音轨解决
5. 偏差超过 0.5 秒 → **重抽这一段**，别硬修

### 高频失败模式

| 症状 | 原因 | 修法 |
|---|---|---|
| 全片系统默认音 | 上传顺序错（音色不在第 4 位） | 重传，音色固定第 4 位 |
| 音色串用 | 多角色没逐个勾「仅当前角色可用」 | 逐角色绑定 |
| 口型全乱 | 时间戳区间重叠 | 检查所有区间无交叠 |
| 部分句子没声音 | 该句时间戳太短 | 单句 = 字数 ÷ 5 + 0.5 秒 |
| 台词说出了奇怪的语言 | 一条里混了语言 | 拆成两条 |
| 音画整体偏 0.3 秒 | 正常范围 | 剪映拖音轨 |

## 五、BGM 与音效设计

### 原则

- **BGM 不要靠模型生成** —— 版权风险 + 无法卡点。**在剪映里加**
- **音效也主要在剪映里补** —— 模型只负责"人声 + 与动作强相关的音效"
- 模型提示词里的 `<>` 只写**画面内必然发声**的东西：开门声、脚步声、玻璃碎裂、钟声

### BGM 情绪走向表（一集 60 秒）

| 段落 | 情绪 | BGM 处理 |
|---|---|---|
| 0–6s | 钩子 | 无 BGM 或有低频持续音，制造不安 |
| 6–20s | 铺陈 | 单音钢琴 / 弦乐长音，音量压低 |
| 20–40s | 冲突升级 | 加入鼓点，渐强 |
| 40–55s | 爆发 | 全编制，鼓点密集 |
| 55–60s | 收尾留钩 | 突然抽掉或留一个悬停和弦 |

**BGM 与台词的音量关系**：台词段 BGM 压到 -18dB 左右；无台词段可以抬起来。

### 音效清单模板（每段都过一遍）

| 类型 | 例子 |
|---|---|
| 环境音 | 宴会厅人声、雨声、风声、车流、空调嗡鸣 |
| 动作音 | 脚步、开门、衣料摩擦、椅子拖动 |
| 强调音 | 玻璃碎裂、耳光、心跳、耳鸣（主观音） |
| 转场音 | whoosh、低频冲击、金属刮擦 |

## 六、音色台本模板

给用户拿去录/合成用，每个角色一段：

```
### 林晚（女主）
- 时长：12 秒
- 内容：随便念一段文字，语气压低、语速慢
- 情绪：克制，不激动
- 环境：安静室内，无背景音乐，无混响
- 导出：WAV / 44100Hz / 不留空白段
- ⚠️ 不要录成朗读腔，要用说话的感觉
```

## 七、音色库归档

- 文件命名：`<角色名>_音色参考_<时长>s.wav`，放在 `02_资产/角色/<角色名>/`
- **系列级资产，做一次全集复用** —— 第 20 集不要重录
- 换了音色 = 换了角色。要改，新建文件并更新角色圣经，别覆盖
