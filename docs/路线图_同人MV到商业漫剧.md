# 路线图 · 同人 MV → 商业漫剧

> 适用：个人创作者，会画画、会做音乐、会 PR + AE，单人制作。
> 路径：**拼贴风同人 MV 练兵 → 完整代表作 → 有台词小剧场 + 原创 IP → 商业（MV/PV 商单 + 原创漫剧）**。
> 方法细节在 `references/12–14`，本文只管「什么时候做什么、做到什么程度算毕业」。
> 编写：2026-10。平台规则、模型许可、工具额度以官方当时公告为准。

---

## 〇、战略

**用「实拍 + 手绘 + 拼贴设计 + AI 补位」的风格，做自己作曲的同人 MV。先练成一套别人很难复制的组合能力，再拿去接商单、做原创。**

| 这个风格要的能力 | 对应 |
|---|---|
| Q 版角色、手写字、涂鸦 | 美术 |
| 一首完整的歌撑起 3–4 分钟 | 音乐 |
| 拼贴动效、实拍合成、动态排版 | PR + AE（`14-AE合成技法.md`） |
| 实拍素材 | 手机 |
| AI | 只在背景、高潮作画镜头、素材生成上补位 |

- AI 比重低，二次元圈接受度高，作品里「人」的部分一眼看得出来
- 游戏公司、虚拟主播、独立歌手买的就是这种 MV / PV，练熟后商单比漫剧分账见钱更快

**同人期带得走的**：生产流程和数据、2D 风格方法、自己的音乐库、账号粉丝、作品集、试过水的原创角色。
**带不走的**：IP 角色本身、IP 带来的流量。

## 一、阶段总览

| 阶段 | 时间（参考） | 做什么 | 主要读 |
|---|---|---|---|
| **0 准备** | 第 1–3 周 | 选 IP、风格圣经、素材库、AE 练习 | 12、13、14 |
| **1 镜头模块短片** | 第 4–11 周 | 4 条 30–90 秒短片，每条主攻一组镜头 | 13 |

时间按每周 15–25 小时估。投入少就拉长，**顺序不要跳**。

## 二、阶段 0：准备（第 1–3 周）

```bash
python scripts/init_project.py --type mv --name <系列名> --role <角色名>
```

- [ ] 选 IP（`12-同人路线.md` 打分表）
- [ ] 风格圣经（`assets/风格圣经模板.md`）
- [ ] 1–2 个角色：设定考据 + 正常比例立绘 + **Q 版 8 个以上动作差分**
- [ ] 拼贴素材第一批：纸张 5、胶带 5、图标 20
- [ ] 系列标题手写字
- [ ] 实拍空镜第一批：20 段，每段 10 秒以上
- [ ] AE 4 个练习（`14-AE合成技法.md` 第三节）
- [ ] AE 模板：贴纸角色预合成、歌词 MOGRT
- [ ] 本地装好超分（Real-CUGAN）和抠图（BiRefNet）

## 三、阶段 1：镜头模块短片（第 4–11 周）

每条 30–90 秒，用你的音乐（可以是一首歌的一段），**每条只主攻一组镜头**（编号见 `13-拼贴风MV.md` 第三节）：

| 编号 | 主题 | 镜头类型 | 练什么 |
|---|---|---|---|
| M1 | 「她在我的日常里」 | 1、2、11 | 跟踪合成、实拍调色、贴纸质感 |
| M2 | 「角色名卡 / 手账」 | 3、4、5 | AE 动态排版、卡点 |
| M3 | 「一个场景的 2.5D 之旅」 | 6、8 | 场景拆层、视差、AI 出场景 |
| M4 | 「副歌高潮」 | 7、9 | 关键帧 → H3 试错 → Seedance 定稿、超分、一拍二 |

每条都要：企划卡 → MV 分镜表（`beat_grid.py` 算拍点、`check_mv_shots.py` 体检）→ 动态分镜 → 素材 → AE 合成 → PR 组装（`make_srt.py` 导歌词）→ 发布 → 48 小时填数据表 → 复盘一处问题。每次生成都记进生成日志。

**毕业标准**
- [ ] 4 条全部发布，每条有数据表和生成日志
- [ ] 12 种镜头类型里至少 9 种做过
- [ ] AE 模板库：贴纸、名卡、歌词、拼贴转场、宫格、职员表
- [ ] 跑过 `log_summary.py`，知道每种镜头类型的平均工时
- [ ] Q 版角色在不同镜头里没有被说「画风不统一」
- [ ] 知道 MiniMax H3 和 Seedance 2.5 各适合什么镜头

---

## 四、阶段 2：完整 MV 代表作（第 12–19 周）

- 一首完整原创曲，3–4 分钟，按 `13-拼贴风MV.md` 的段落配比做
- 时间：作曲 2 周 → 分镜、动态分镜和素材 2 周 → AE 合成 3 周 → 收尾发布 1 周
- 发布前按 `13-拼贴风MV.md` 第十二节的验收清单逐条打钩
- 同时出：30–60 秒副歌切片（竖版发抖音、小红书）+ 一条幕后视频

**毕业标准**
- [ ] 完整 MV、副歌切片、幕后视频都发布
- [ ] 分镜、素材、AE 工程完整归档，能复用到下一支
- [ ] 原创曲做了确权（音乐平台原创认证 / 作品登记，见 `15-商单与交付.md` 第九节）

---

## 五、阶段 3：小剧场 + 原创孵化（第 20–32 周）

| 线 | 内容 | 目的 |
|---|---|---|
| 同人小剧场 | 60–120 秒，有台词，用拼贴风包装 | 接上本仓库主流程：分镜表 → `build_prompts.py` → Seedance 2.5 |
| 原创角色 MV | 原创角色 + 原创曲，同一套风格 | 验证粉丝跟你还是跟 IP；成品链路换成可商用模型 |

画幅切到 9:16 练竖屏；有连续剧情就填剧情状态表，用 `check_consistency.py` 跑跨集检查。

**毕业标准**
- [ ] 小剧场 ≥ 5 条，音色绑定稳定（脚本检查没有「没挂音色」）
- [ ] 原创角色 MV 发布，和同人作品有数据对比
- [ ] 原创资产库完整：角色（正常 + Q 版）、风格圣经、主题曲

---

## 六、阶段 4：转商业

检查清单和商业方向见 `12-同人路线.md` 第八节。建议顺序：

1. **MV / PV 商单**养活生产线：代表作 + 幕后视频 + 报价单（工时和成本来自 `log_summary.py`）。接单流程、需求确认单、报价、合同要点、交付规格见 `15-商单与交付.md`
2. 主号连载**原创 IP**
3. 原创跑出数据，再走 `01–11` 的**商业漫剧**流程上分账平台（先查入驻要求和微短剧备案）

## 七、预算与节奏

| 档位 | 配置 | 阶段 |
|---|---|---|
| 最省 | 实拍 + 手绘 + 本地模型（Anima / Z-Image / Qwen-Image / MiniMax H3）+ 即梦免费额度 | 0–1 |
| 常规 | 加即梦会员（Seedream / Seedance 定稿） | 2 起 |
| 加速 | 加 GPT Image 2.5 等按需付费 | 3 起 |

固定开销：Adobe 订阅（不想付就用达芬奇免费版）。

**阶段 1 两周一条**：

| | 第 1 周 | 第 2 周 |
|---|---|---|
| 周一 | 企划卡、音乐段落 | AE 合成 |
| 周二 | MV 分镜表 | AE 合成 |
| 周三 | 实拍（挑天气好的日子） | PR 组装、歌词、调色 |
| 周四 | 画 Q 版差分、手写字 | 封面、切片 |
| 周五 | AI 补素材；晚上挂机跑超分 | 发布 |
| 周末 | 拍摄补漏 / 休息 | 回评论、复盘、更新素材库 |

做得慢就三周一条，**宁可慢，不要断更后放弃**。

**备份**：本地素材库和项目文件夹是唯一真源，平台资产库只当缓存；每条定稿后同步到网盘或移动硬盘；模型升级后先拿以前做过的 2–3 个镜头重跑，确认效果没变再用。

## 八、别做的事

- ❌ 第一条就做 4 分钟完整 MV（先做模块短片）
- ❌ 每个镜头都丢给视频模型抽卡（能用 AE 做的不进模型）
- ❌ 用官方 PV 画面、官方立绘当主要素材
- ❌ 用原作 OST、克隆声优声音
- ❌ 同时开两个以上 IP
- ❌ 同人期开 IP 相关的商业变现
- ❌ 隐藏 AI 身份
- ❌ 4 条数据不到就换 IP、换风格
