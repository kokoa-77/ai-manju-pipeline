# 项目目录与命名规范

从**第一个文件**开始就按这个建。20 集 × 每集 6–8 段素材，乱放一次就再也找不回来了。

**一键建好**：`python scripts/init_project.py --type manju --name <剧名>`（目录 + 模板全部放好，已存在的文件不会被覆盖）。
同人 / 拼贴风 MV 项目用 `--type mv`，目录见 `references/13-拼贴风MV.md` 第六节。

## 二、命名规则

```
<主体>_<类型>_<变体>_v<序号>.<扩展名>
```

| 片段 | 取值 | 例子 |
|---|---|---|
| 主体 | 角色名 / 场景名 / 道具名（中文，不缩写） | `林晚` `婚礼彩排厅` `银色项链` |
| 类型 | `三视图` `定妆` `表情` `空镜` `白底` `音色参考` `seg` | `三视图` |
| 变体 | 视角 / 情绪 / 状态，没有就省略 | `正面` `落泪` `微醺` |
| v 序号 | 从 1 开始，**改了就加号，不覆盖** | `v3` |

**音色参考例外**：用时长代替 v 序号，`林晚_音色参考_12s.wav`；换音色等于换角色，新文件要换时长或加 `_v2`，别覆盖。

**成片片段一律用 `seg<两位段号>`**：`seg01` `seg02` …… `seg12`。段号必须和分镜表里的段号一致。

## 三、三条硬规矩

1. **不覆盖旧文件。** 抽卡出来的废片也有信息量（"什么样的提示词会崩"），改成 `_vN` 留着。
2. **文件名里不出现空格和特殊符号。** 用下划线连接，避免同步和脚本处理时炸掉。
3. **`_素材编号表.csv` 是唯一真相来源。** 分镜表引用的编号只有在这一张表里才能查到含义；任何时候不要凭记忆写编号。提示词里的 `@图片N` 是每条生成的上传槽位，由 `build_prompts.py` 换算（见 `references/02` 第五节）。

## 四、系列圣经要锁死什么

`00_项目卡/系列圣经.md` 是第 1 集和第 20 集长得一样的保证。固定写死这几项，之后**每一条提示词都从它抄**：

| 项 | 示例 |
|---|---|
| 画风 | 电影级 3D 写实渲染 / 日式赛璐璐 / 国漫厚涂 |
| 主色调 | 酒红 + 象牙白 |
| 次色调 | 香槟金 |
| 点缀色 | 烛火橙黄 |
| 光照逻辑 | 室内暖金主光 + 侧逆光，暗部压到底 |
| 画幅 | 9:16 竖屏，安全区内构图 |
| 时代 / 地域 | 当代都市，中国一线城市 |
| **禁项** | 不要字幕、不要 BGM、不要水印、不要画面内文字、不要多余人脸 |
