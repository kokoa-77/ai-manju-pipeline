# 分镜表模板

**两套文件，同一份内容**：
- `第NN集_分镜表.csv` —— 机器读的，喂给 `scripts/build_prompts.py`。空白模板：`assets/分镜表模板.csv`（`init_project.py` 会自动复制）
- `第NN集_分镜表.md` —— 人读的，表格版

---

## 一、CSV 列定义（列名固定，脚本按列名读）

| 列名 | 必填 | 说明 |
|---|---|---|
| `段号` | ✅ | `seg01` `seg02`…… 与成片文件名一致 |
| `时间区间` | ✅ | 段内相对时间，`0s-3s`。**同段内不得重叠** |
| `段时长` | ✅ | 段总时长（秒），4–12，推荐 6–10。写数字；写成 `10秒` 脚本也能认 |
| `段概述` | ✅ | 一句话概述（主体 + 地点 + 事件 + 风格 + 运镜）。同段只填第一行 |
| `场景` | ✅ | 内景/外景 + 地点，如 `内景·婚礼彩排晚宴厅` |
| `景别` | ✅ | 大远景/远景/全景/中景/中近景/近景/特写/大特写 |
| `运镜` | ✅ | 固定机位/缓慢推近/横摇/平移跟拍/环绕…… + **视角词** |
| `画面内容` | ✅ | 写"看到什么"，不写情绪形容词 |
| `动作细节` | ✅ | 肢体细化 + 程度量化 |
| `台词` | | 原文，**不带 `{}`**（脚本自动加） |
| `说话人` | | 角色姓名，**不许写"角色1"** |
| `音效` | | **不带 `<>`**（脚本自动加） |
| `参考素材` | ✅ | `@图片1;@图片6`，分号分隔，写**编号表编号**；脚本会换算成上传槽位。**有台词的角色必须挂自己的 `@音频N`** |
| `段守则` | | 本段红线；留空则用默认守则 |
| `合并到` | | 填**紧接着的下一个段号**，表示两段合并成一条生成（A 派）；输出以本段号命名。留空 = 独立生成 |
| `备注` | | 给人看的，不进提示词 |

## 三、时长分配公式

| 一集时长 | 建议段数 | 每段时长 |
|---|---|---|
| 60 秒 | 6 段（B 派）/ 2 段（A 派合并） | 6–10 秒 |
| 90 秒 | 8–9 段 | 6–10 秒 |
| 120 秒 | 10–12 段 | 6–10 秒 |

**超过 12 秒的段明显变质**（10–12 秒已是上限区）—— 模型在长段里会自己加戏，宁可多分一段。
**合并后的总时长不得超过 30 秒**（单次生成上限）。

**台词密度**：中文按 **5 字/秒**。单句 6–14 字。单段（6–10 秒）台词总量 ≤ 2 句 / ≤ 25 字。单句时间戳 = 字数 ÷ 5 + 0.5 秒缓冲。

## 四、景别节奏检查（填完后过一遍）

- [ ] 没有连续 3 段同景别
- [ ] 每 3 段至少 1 个特写
- [ ] 每 3 段至少 1 个带运动的镜头
- [ ] 同一段内景别不超过 2 种变化
- [ ] 段与段的转场方式已标注（硬切 / 动作接动作 / 声先入）
- [ ] 连续性对得上：服装、发型、光线方向、道具位置、人物站位、时间
